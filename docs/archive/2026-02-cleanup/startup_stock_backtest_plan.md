# 已启动股票回测方案

## 📊 回测目标

评估"已启动"股票策略的历史表现，包括：
- 收益率统计（总收益率、平均收益率、胜率）
- 风险指标（最大回撤、波动率、夏普比率）
- 持有期分析（平均持有天数、最佳/最差持有期）
- 退出原因分析（死叉、止盈、止损、时间限制等）

## 🎯 回测策略设计

### 1. 买入信号
- **信号来源**：`fact_stock_startup_candidate` 表中 `stage='confirmed'` 或 `stage='started'` 的记录
- **买入时机**：入选日期（`trade_date`）的**第二天开盘价**
- **买入价格**：入选日下一个交易日的开盘价（`FactDailyPriceQfq.open`）
- **说明**：入选日当天可能已经收盘，无法买入，因此使用第二天开盘价买入更符合实际交易场景

### 2. 卖出策略（多种策略可选）

#### 策略1：死叉退出（默认）
- **退出条件**：5日线下穿10日线（死叉）
- **适用场景**：跟踪趋势，死叉时退出
- **优点**：符合当前系统的退出逻辑
- **缺点**：可能错过后续反弹

#### 策略2：止盈止损
- **止盈目标**：默认 +50%
- **止损比例**：默认 -10%
- **退出条件**：达到止盈或止损目标
- **适用场景**：风险控制明确，追求更高收益

#### 策略3：破5日线退出
- **退出条件**：收盘价跌破5日线
- **适用场景**：趋势跟踪，破线即退出
- **优点**：及时止损

#### 策略4：破10日线退出
- **退出条件**：收盘价跌破10日线
- **适用场景**：给股票更多上涨空间
- **优点**：减少过早退出

#### 策略5：组合策略（推荐）
- **止盈**：+50% 或 +30%（可配置）
- **止损**：-10% 或破5日线
- **时间限制**：最大持有30个交易日
- **死叉退出**：5日线下穿10日线
- **优先级**：止盈 > 止损 > 死叉 > 时间限制

### 3. 资金管理

#### 方案A：等权重分配（推荐）
- **初始资金**：30万元
- **每只股票**：3万元（固定金额）
- **每天最多买入**：10只股票
- **优点**：简单易行，风险分散

### 4. 交易成本
- **买入手续费**：0.03%（万三）
- **卖出手续费**：0.03%（万三）
- **印花税**：0.1%（仅卖出时收取）
- **总成本**：约 0.16%（买入+卖出）

## 📈 回测指标

### 1. 收益指标
- **总收益率**：`(最终资产 - 初始资金) / 初始资金 * 100%`
- **年化收益率**：`(1 + 总收益率) ^ (365 / 回测天数) - 1`
- **平均单笔收益率**：所有交易的平均收益率
- **胜率**：盈利交易数 / 总交易数
- **盈亏比**：平均盈利 / 平均亏损

### 2. 风险指标
- **最大回撤**：从最高点到最低点的最大跌幅
- **波动率**：收益率的标准差
- **夏普比率**：`(年化收益率 - 无风险利率) / 波动率`
- **最大连续亏损次数**：连续亏损的最大次数
- **最大单笔亏损**：单笔交易的最大亏损

### 3. 持有期分析
- **平均持有天数**：所有交易的平均持有天数
- **最短持有天数**：单笔交易的最短持有天数
- **最长持有天数**：单笔交易的最长持有天数
- **持有期分布**：按持有天数分组的交易数量

### 4. 退出原因分析
- **死叉退出**：5日线下穿10日线的交易数及平均收益率
- **止盈退出**：达到止盈目标的交易数及平均收益率
- **止损退出**：达到止损目标的交易数及平均收益率
- **时间限制退出**：达到最大持有天数的交易数及平均收益率
- **其他退出**：其他原因的退出情况

### 5. 分阶段分析
- **按得分分组**：score >= 100, 70-99, 60-69 的表现对比
- **按风险分组**：有风险 vs 无风险的表现对比
- **按辅助条件分组**：辅助条件数量对收益的影响
- **按入选日期分组**：不同时期的策略表现

## 🗄️ 数据库设计

### 表结构：`fact_startup_stock_backtest`

```sql
CREATE TABLE IF NOT EXISTS fact_startup_stock_backtest (
    -- 主键
    id BIGSERIAL PRIMARY KEY,
    
    -- 信号信息
    signal_date DATE NOT NULL,  -- 入选日期（trade_date）
    ts_code VARCHAR(20) NOT NULL,  -- 股票代码
    stock_name VARCHAR(100),  -- 股票名称
    
    -- 入选信息
    entry_score INTEGER,  -- 入选时的得分
    entry_stage VARCHAR(20),  -- 入选时的阶段（confirmed/started）
    risk_passed BOOLEAN,  -- 是否有风险
    assist_count INTEGER,  -- 辅助条件数量
    passed_signals TEXT[],  -- 通过的信号列表
    risk_reasons TEXT[],  -- 风险原因列表
    
    -- 交易信息
    buy_date DATE NOT NULL,  -- 买入日期（入选日的下一个交易日）
    buy_price NUMERIC(12, 4) NOT NULL,  -- 买入价格（入选日下一个交易日的开盘价）
    sell_date DATE,  -- 卖出日期
    sell_price NUMERIC(12, 4),  -- 卖出价格
    
    -- 收益信息
    return_pct NUMERIC(8, 4),  -- 收益率（小数，如0.15表示15%）
    hold_days INTEGER,  -- 持有天数（交易日）
    exit_reason VARCHAR(50),  -- 退出原因
    
    -- 资金管理信息
    buy_amount NUMERIC(20, 2),  -- 买入金额（元）
    buy_quantity INTEGER,  -- 买入数量（股）
    sell_amount NUMERIC(20, 2),  -- 卖出金额（元）
    profit_loss NUMERIC(20, 2),  -- 盈亏金额（元）
    profit_loss_pct NUMERIC(8, 4),  -- 盈亏比例（%，如-8.17表示-8.17%）
    
    -- 回测参数
    sell_strategy VARCHAR(50),  -- 卖出策略：dead_cross, profit_stop, ma5_loss, ma10_loss, combined
    profit_target NUMERIC(8, 4),  -- 目标收益率（如0.50表示50%）
    stop_loss NUMERIC(8, 4),  -- 止损比例（如-0.10表示-10%）
    max_hold_days INTEGER,  -- 最大持有天数
    
    -- 时间戳
    created_at TIMESTAMP DEFAULT NOW(),
    
    -- 索引
    INDEX idx_backtest_signal_date (signal_date),
    INDEX idx_backtest_ts_code (ts_code),
    INDEX idx_backtest_buy_date (buy_date),
    INDEX idx_backtest_exit_reason (exit_reason),
    INDEX idx_backtest_sell_strategy (sell_strategy)
);
```

## 💻 实现方案

### 1. 回测服务类：`StartupStockBacktestService`

**文件位置**：`backend/services/stock/startup_stock_backtest_service.py`

**主要方法**：
- `backtest_strategy()`: 执行回测主方法
- `_get_signals()`: 获取已启动股票信号
- `_get_next_trading_day()`: 获取下一个交易日（用于确定买入日期）
- `_get_price_data()`: 批量获取价格数据（包含开盘价）
- `_check_exit_conditions()`: 检查退出条件
- `_calculate_statistics()`: 计算统计指标
- `_save_backtest_results()`: 保存回测结果到数据库

**买入逻辑说明**：
- 对于每个入选信号（`signal_date`），需要找到下一个交易日作为买入日期（`buy_date`）
- 买入价格为 `buy_date` 当天的开盘价（`FactDailyPriceQfq.open`）
- 如果下一个交易日没有数据（停牌、退市等），则跳过该信号

### 2. API接口

**文件位置**：`backend/api/startup/backtest.py`

**接口设计**：

## ⚠️ 注意事项

1. **买入日期处理**：
   - 入选日（`signal_date`）的下一个交易日作为买入日期（`buy_date`）
   - 如果下一个交易日没有开盘价数据（停牌、退市等），则跳过该信号
   - 需要查询交易日历或价格表来确定下一个交易日

2. **数据完整性**：确保价格数据完整，缺失数据需要处理
3. **停牌处理**：停牌期间无法交易，需要跳过
4. **ST股票**：建议排除ST股票和退市股票
5. **新股处理**：新股可能数据不足，需要特殊处理
6. **交易成本**：需要准确计算交易成本
7. **滑点**：实际交易可能存在滑点，回测中可考虑加入滑点模拟
8. **资金限制**：需要处理资金不足的情况
9. **开盘价获取**：确保买入日有开盘价数据，如果没有则使用收盘价或跳过
