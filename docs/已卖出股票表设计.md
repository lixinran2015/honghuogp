# 已卖出股票表设计文档

## 1. 表结构概述

**表名**: `fact_sold_stock`  
**用途**: 记录已卖出股票的表现分析，用于评估卖出决策的正确性

## 2. 字段设计

### 2.1 基本信息
- **id** (BIGSERIAL): 主键，自增
- **ts_code** (VARCHAR(20)): 股票代码（Tushare格式，如 `600519.SH`）
- **stock_name** (VARCHAR(50)): 股票名称（冗余存储，方便查询）

### 2.2 卖出信息
- **sell_date** (DATE): 卖出日期

### 2.3 卖出后表现分析
- **change_5d_after_sell** (NUMERIC(8, 4)): 卖出后5日涨幅（卖出后5个交易日的涨幅，单位：%）
- **change_10d_after_sell** (NUMERIC(8, 4)): 卖出后10日涨幅（卖出后10个交易日的涨幅，单位：%）
- **is_above_ma10** (BOOLEAN): 是否站稳10日线（卖出后是否在10日线上方）
- **is_above_ma20** (BOOLEAN): 是否站稳20日线（卖出后是否在20日线上方）
- **is_above_ma30** (BOOLEAN): 是否站稳30日线（卖出后是否在30日线上方）

### 2.4 其他信息
- **notes** (TEXT): 备注信息

### 2.5 时间戳
- **created_at** (TIMESTAMP): 创建时间（自动设置）
- **updated_at** (TIMESTAMP): 更新时间（自动更新）

## 3. 索引设计

1. **idx_sold_stock_ts_code**: 按股票代码索引（方便按股票查询）
2. **idx_sold_stock_sell_date**: 按卖出日期降序索引（方便按卖出时间查询）
3. **idx_sold_stock_change_5d**: 按卖出后5日涨幅降序索引（方便排序）
4. **idx_sold_stock_change_10d**: 按卖出后10日涨幅降序索引（方便排序）

## 4. 使用场景

### 4.1 数据录入
- 用户手动录入已卖出的股票
- 系统自动计算卖出后5日/10日涨幅
- 系统自动判断是否站稳各均线

### 4.2 数据查询
- 按股票代码查询历史卖出记录
- 按卖出日期范围查询
- 按卖出后涨幅排序（找出卖早/卖晚的情况）
- 按是否站稳均线筛选

### 4.3 统计分析
- 统计卖出后继续上涨的比例
- 统计卖出后站稳均线的比例
- 分析卖出时机是否合适

## 5. 示例数据

```sql
INSERT INTO fact_sold_stock (
    ts_code, stock_name, sell_date,

    notes

    '600519.SH', '贵州茅台', '2024-12-08',
    5.23, 8.45,
    true, true, false,
    '达到目标价位，止盈卖出'
);
```

## 6. 计算逻辑说明

### 6.1 卖出后5日涨幅
- 从卖出日期往后找5个交易日
- 计算：`(第5个交易日收盘价 - 卖出日收盘价) / 卖出日收盘价 * 100`

### 6.2 卖出后10日涨幅
- 从卖出日期往后找10个交易日
- 计算：`(第10个交易日收盘价 - 卖出日收盘价) / 卖出日收盘价 * 100`

### 6.3 是否站稳均线
- 判断卖出后某个交易日（如卖出后5日）的收盘价是否在对应均线上方
- `is_above_ma10`: 卖出后5日收盘价 >= 10日均线
- `is_above_ma20`: 卖出后5日收盘价 >= 20日均线
- `is_above_ma30`: 卖出后5日收盘价 >= 30日均线

## 7. API接口设计建议

### 7.1 创建卖出记录
- **POST** `/api/sold-stock`
- 请求体：股票代码、股票名称、卖出日期、备注
- 自动计算卖出后涨幅和均线状态

### 7.2 查询卖出记录
- **GET** `/api/sold-stock`
- 支持筛选：股票代码、卖出日期范围
- 支持排序：按卖出日期、卖出后涨幅等

### 7.3 更新卖出记录
- **PUT** `/api/sold-stock/{id}`
- 更新卖出信息（重新计算涨幅和均线状态）

### 7.4 删除卖出记录
- **DELETE** `/api/sold-stock/{id}`
- 删除记录

### 7.5 重新计算
- **POST** `/api/sold-stock/{id}/recalculate`
- 重新计算卖出后涨幅和均线状态（用于数据更新）
