# 根目录整理说明

> 2026-02 整理，将散落脚本与文档归类。

## 变更概览

### 1. 新增 `scripts/` 目录

原先位于项目根目录的 Python 脚本、批处理文件已移动到 `scripts/` 下，按用途分类：

| 子目录 | 说明 | 示例 |
|-------|------|------|
| `backfill/` | 数据回填 | backfill_startup_history.py |
| `check/` | 各类检查 | check_started_stocks.py |
| `manual/` | 手动操作 | add_yingweike_to_started.py |
| `fix/` | 修复脚本 | fix_confirmed_stage_error.py |
| `analyze/` | 日志/数据分析 | analyze_broken_ma.py |
| `test/` | API/功能测试 | test_watch_api.py |
| `tools/` | 通用工具 | find_stock.py |
| `batch/` | 批处理 | init_database.bat |

详见 `scripts/README.md`。

### 2. 文档归入 `docs/`

以下文档从根目录移动到 `docs/`：

- API调用示例.md
- PACKAGE_CONTENTS.md、PACKAGE_README.md
- PostgreSQL安装指南_Windows.md
- 快速开始指南.md、安装指南_Windows.md
- 数据库初始化说明.md、数据库导入说明.md、数据库导入导出.md、数据库说明.md、数据库导入错误解决.md
- 同花顺接口使用说明.md
- 配置指南.txt
- thx.txt

根目录保留：`README.md`、`INSTALL.md`。

### 3. 其他调整

- `app.py`（已废弃的 Streamlit 入口）→ `old/`
- `delete_started_stocks.sql` → `data_warehouse/sql/`
- 批处理脚本（`init_database.bat`、`import_database.bat` 等）→ `scripts/batch/`，脚本内已增加 `cd` 到项目根目录，保证相对路径正确

### 4. 保持不变的根目录文件

- `run.py` - 主入口
- `akshare_safe_wrapper.py` - 数据封装（backend 直接依赖）
- `config.json`、`requirements.txt`、`package.json`
- `README.md`、`INSTALL.md`
- `start_all.bat`、`start_backend.bat`、`start_frontend.bat`、`quick_start.sh` 等启动脚本

## 使用说明

执行脚本时请在**项目根目录**运行，例如：

```bash
python scripts/backfill/backfill_startup_history.py --days 10
scripts\batch\generate_startup_data.bat
```
