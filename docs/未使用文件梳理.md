## 三、当前主程序实际使用

### 启动链

```
start_backend.bat / start_all.bat
  → cd backend && python run.py
    → uvicorn app:app
      → backend/app.py
        → 各 API 路由、DataWarehouse、DataScheduler
```

### 核心依赖

- `backend/`：API、services、utils
- `data_warehouse/`：db、models、service、config
- `utils/config_manager.py`：AI、Tushare 等配置
- `config.json`：主配置
- `config/`：业务配置（如 long_term_themes.json）
- `data/eastmoney_industry_list.json`：板块行业数据
- `drivers/`：ChromeDriver（爬虫/定时任务）
- `migrations/`：行业龙头等脚本引用
- `frontend-vue/`：Vue3 前端

### 根目录保留建议

| 保留 | 说明 |
|------|------|
| `config.json` | 主配置 |
| `requirements.txt` | Python 依赖 |
| `README.md`、`INSTALL.md` | 文档 |
| `akshare_safe_wrapper.py` | 仍被 DataInitializer、etl 等引用 |
| `start_*.bat`、`start_*.sh` | 启动脚本 |
| `scripts/` | 运维/排障脚本 |
