## 启动龙头交易规则说明（v0.1）

> 目标：围绕「短线启动龙头」，统一买点 / 止损 / 第一目标价的计算规则，并在推荐池、回测、诊断等所有入口保持一致，避免「看起来是同一套策略，实际各处规则不一样」的问题。

---

### 一、适用范围

本规则适用于：

- 已通过「启动筛选」的股票（阶段为 `confirmed` 或 `started`）；
- 推荐池中由 `StockRecommendationService` 写入的标的；
- 启动整体回测中每一笔模拟交易；
- 单票诊断页（`StockDiagnoseView`）展示的「建议交易计划」。

未来如有新的「启动风格」或「周期风格」策略，可在此规则基础上派生版本，但本文件描述的是当前默认行为。

---

### 二、统一的计算入口：`compute_trade_plan`

代码位置：`backend/services/stock/trade_plan_utils.py`

核心函数：

```python
compute_trade_plan(entry_price: float, stock_data: Optional[Dict] = None) -> Dict
```

返回字段：

- `entry_price`：参考买入价（通常是**启动确认日收盘价**或当前诊断日收盘价）。
- `buy_range`: `[low, high]` 建议买入区间（默认 ±2%，可配置）。
- `stop_loss_price`：建议止损价。
- `take_profit_price`：第一目标价。
- `expected_return_pct`：从参考买入价到第一目标价的预期收益（%）。
- `stop_loss_pct`：从参考买入价到止损价的跌幅（%）。
- `buy_range_pct`：买入价带宽（%），例如 2.0 表示 ±2%。
- `target_source`：目标价的来源说明（见下一节）。

所有使用买点/止损/目标价的地方，都应通过此函数获得交易计划，避免在各自模块内重新实现一遍。

---

### 三、第一目标价的来源逻辑

目标价的计算由 `_compute_target_from_resistance` 负责（内部函数），规则如下：

1. **优先使用 90 日收盘价最高价**  
   - 若 `high_90d > 0` 且 `high_90d > entry_price`：
     - `take_profit_price = high_90d`
     - `target_source = "90日高点"`

2. **否则使用 120 日收盘价最高价**  
   - 若不满足上条，且 `high_120d > 0` 且 `high_120d > entry_price`：
     - `take_profit_price = high_120d`
     - `target_source = "120日高点"`

3. **若无有效压力位（已突破前高或数据缺失）**  
   - 使用保守比例 `10%`（1.10 倍）：
     - `take_profit_price = entry_price * 1.10`
     - `target_source = "无压力位(10%)"`

4. **完全没有技术面数据时（例如仅有价格）**  
   - `stock_data is None` 的情况下：
     - 使用配置 `recommendation_defaults.target_1_pct`（默认 1.20，即 +20%）：
       - `take_profit_price = entry_price * target_1_pct`
       - `target_source = "默认目标价"`

结论：  
**启动票大多数已经突破 90 日高点，因此很多情况下第一目标价会落在 120 日高点或默认 10% 附近**，这一点在回测和诊断结果中都能看到。

---

### 四、止损价与买入区间的计算

#### 1. 止损价

来自配置 `recommendation_defaults.stop_loss_pct`（默认 `0.94`，即 -6%）：

- `stop_loss_price = entry_price * stop_loss_pct`
- `stop_loss_pct` 字段为：
  \[
    \frac{\text{stop\_loss\_price}}{\text{entry\_price}} - 1
  \]
  例如从 10 元到 9.4 元，对应 -6.0%。

配置位置示意（`config.json`）：

```json
"trading_config": {
  "recommendation_defaults": {
    "target_1_pct": 1.20,
    "stop_loss_pct": 0.94,
    "entry_range_pct": 0.02
  }
}
```

#### 2. 建议买入区间

使用 `entry_range_pct`（默认 `0.02`，即 ±2%）：

- 下沿：`entry_price * (1 - entry_range_pct)`
- 上沿：`entry_price * (1 + entry_range_pct)`
- 前端展示为「`[low, high] 元（±X.X%）`」。

用途：

- 给出一个「合理挂单区间」，而不是单点位；  
- 同时也方便回测时判断「实际买入价是否偏离计划过多」。

### 五、在各模块中的具体使用方式

#### 1. 推荐池（`StockRecommendationService`）

位置：`backend/services/recommendation/stock_recommender.py`

- 在 `_add_to_recommendation` 中：
  - 使用 **启动确认日** 收盘价作为 `entry_price`；
  - 调用 `compute_trade_plan(entry_price, stock_data)`；
  - 将 `take_profit_price` / `stop_loss_price` 直接写入 `FactRecommendedStock`；
  - 日志中会打印：
    - 入选价
    - 目标价
    - 预期收益 `%`
    - 目标来源（90日高点/120日高点/无压力位/默认）。

#### 2. 启动整体回测（`StartupBacktestService`）

位置：`backend/services/stock/startup_backtest_service.py`

- 在 `_execute_buy` 中：
  - 使用 **买入日开盘价** 作为 `entry_price`（回测中不再查高点，仅用默认比例）；
  - 调用 `compute_trade_plan(buy_price, stock_data=None)`；
  - 将 `stop_loss_price` / `take_profit_price` 加入 `trade` 记录，随回测结果一并返回。

这部分目前用于后续扩展，例如在回测报告中对比「按计划执行」的结果。

#### 3. 单票诊断（`/api/startup/diagnose`）

位置：`backend/api/startup/diagnose.py`

- 在诊断逻辑的收尾部分：
  - 使用 **诊断日收盘价** 作为 `entry_price`；
  - 调用 `compute_trade_plan(entry_price, stock_data)`；
  - 将结果放入返回的 `diagnosis['trade_plan']`。

前端 `StockDiagnoseView.vue` 中渲染为：

- 参考买入价 + 买入区间；
- 建议止损价（及相对跌幅）；
- 第一目标价（及预期收益、来源标签）；
- 当前收盘价相对参考买入价的涨跌幅。

#### 4. 启动回测信号列表（`/api/startup/backtest-signals`）

位置：`backend/api/startup/backtest_data.py`

- 以 **入选日价格** 作为参考买入价：
  - 优先 `FactStockStartupCandidate.latest_price`；
  - 否则查 `fact_daily_price_qfq.close`（入选日收盘价）。
- 调用 `compute_trade_plan(entry_price, stock_data=None)`；
- 将 `trade_plan` 挂在每条 `signal` 上，前端 `StartupBacktestView` 中显示为「买/损/目」三行价格。

### 六、实际使用时的解读建议

1. **参考买入价 vs 当前价**  
   - 当前收盘价相对参考买入价的偏离可以快速告诉你：
     - 是否已经「明显偏离计划买点」（例如 +10% 以上）；  
     - 是否处于「计划区间附近」。

2. **止损价**  
   - 以 `-6%`（默认）作为「策略级别」的初始风险控制；
   - 实际操作中，可以根据个股波动和个人偏好进行微调，但原则上不建议放得更宽。

3. **第一目标价**  
   - 若来源为「90日高点 / 120日高点」，说明当前价位距离历史压力位还有多少空间；
   - 若为「无压力位(10%) / 默认目标价」，更多是一种保守预期（10%~20%），在后续统计中可以评估其是否合理。

4. **统一性**  
   - 推荐池、诊断页、回测页面看到的价位**来自同一套计算逻辑**；
   - 当你调整 `config.json` 中的默认参数时，所有相关模块会一起生效。

### 七、后续演进方向（备忘）

1. **与真实成交价对齐**  
   - 在回测和实盘数据中，对比「实际成交价」与 `entry_price` / `buy_range` 的偏离，优化挂单策略。

2. **多阶段目标价**  
   - 在第一目标价基础上增加第二目标（例如突破 120 日高点后按更长周期高点计算）。

3. **风格化参数集**  
   - 为不同风格定义不同的参数集（例如「更激进的追龙头版本」使用更紧的止损、更高的目标价倍数），并通过配置切换。
