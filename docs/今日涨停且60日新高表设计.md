# 今日涨停且60日新高表设计文档

## 表名
`fact_limit_up_today_60d_high`

## 表说明
记录每日计算的"今日涨停且60日新高"股票结果。该表用于持久化存储计算结果，支持历史查询和数据分析。

## 表结构

### 字段说明

| 字段名 | 类型 | 说明 | 是否可空 | 索引 |
|--------|------|------|---------|------|
| id | BIGSERIAL | 主键ID | 否 | PRIMARY KEY |
| trade_date | DATE | 计算日期 | 否 | ✓ |
| ts_code | VARCHAR(20) | 股票代码（Tushare格式，如 600519.SH） | 否 | ✓ |
| stock_name | VARCHAR(100) | 股票名称（冗余存储，方便查询） | 是 | - |
| rank_position | INTEGER | 人气榜排名 | 是 | ✓ |
| rank_change | INTEGER | 排名变动（正数=上升，负数=下降） | 是 | - |
| max_rank | INTEGER | 计算时使用的人气榜范围（前N名） | 是 | - |
| today_close | NUMERIC(10, 2) | 今日收盘价 | 是 | - |
| change_pct | NUMERIC(8, 4) | 今日涨幅（%） | 是 | - |
| change_5d | NUMERIC(8, 4) | 近5日涨幅（%） | 是 | ✓ |
| change_10d | NUMERIC(8, 4) | 近10日涨幅（%） | 是 | ✓ |
| is_60d_high | BOOLEAN | 是否60日新高 | 是 | ✓ |
| created_at | TIMESTAMP | 创建时间 | 否 | - |
| updated_at | TIMESTAMP | 更新时间 | 否 | - |

### 唯一约束
- `(trade_date, ts_code)` - 同一日期同一股票只保存一条记录

### 索引
- `idx_limit_up_60d_trade_date` - 按计算日期降序索引
- `idx_limit_up_60d_ts_code` - 按股票代码索引
- `idx_limit_up_60d_rank_position` - 按人气榜排名索引
- `idx_limit_up_60d_change_5d` - 按近5日涨幅降序索引
- `idx_limit_up_60d_change_10d` - 按近10日涨幅降序索引
- `idx_limit_up_60d_is_60d_high` - 按是否60日新高索引

## 使用场景

### 1. 历史查询
查询指定日期的计算结果：
```sql
SELECT * FROM fact_limit_up_today_60d_high 
WHERE trade_date = '2025-12-08' 
ORDER BY rank_position;
```

### 2. 股票追踪
查询某只股票的历史记录：
```sql
SELECT * FROM fact_limit_up_today_60d_high 
WHERE ts_code = '600519.SH' 
ORDER BY trade_date DESC;
```

### 3. 涨幅分析
查询近5日涨幅最大的股票：
```sql
SELECT * FROM fact_limit_up_today_60d_high 
WHERE trade_date = '2025-12-08' 
ORDER BY change_5d DESC 
LIMIT 10;
```

### 4. 统计汇总
统计每日符合条件的股票数量：
```sql
SELECT trade_date, COUNT(*) as count 
FROM fact_limit_up_today_60d_high 
GROUP BY trade_date 
ORDER BY trade_date DESC;
```

## 数据保存逻辑

### 自动保存
当调用 `/api/startup/limit-up-today-60d-high` API 时，计算完成后会自动保存结果到数据库。

### 保存策略
- **插入新记录**：如果该日期和股票代码的组合不存在，则插入新记录
- **更新现有记录**：如果已存在，则更新所有字段（包括 `updated_at` 时间戳）

### 保存时机
- 计算完成后立即保存
- 保存失败不影响API返回结果（仅记录警告日志）

## 计算逻辑说明

### 筛选条件
1. **今日涨停**：今日收盘价相对于昨日收盘价的涨幅达到涨停（主板10%，创业板/科创板20%）
2. **60日新高**：今日收盘价 >= 最近60个交易日的最高收盘价
3. **近5日涨幅 < 30%**：近5日涨幅必须小于30%（如果数据不足则包含）

### 数据来源
- **价格数据**：从 `fact_daily_price_qfq` 表获取
- **人气榜数据**：从 `fact_guba_popularity_rank` 表获取
- **股票基本信息**：从 `dim_stock` 表获取

## 相关API

### 计算并保存
- **接口**：`GET /api/startup/limit-up-today-60d-high`
- **参数**：
  - `trade_date`：计算日期（格式YYYY-MM-DD，默认今天）
  - `max_rank`：最高排名（默认前100名）
- **返回**：计算结果列表（同时自动保存到数据库）
