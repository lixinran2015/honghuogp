# 🔌 数据库账号密码配置说明

## 📍 配置文件位置

数据库配置在 **`data_warehouse/config.py`** 文件中。

## 🔧 配置方式

### 方式1: 直接在代码中配置（简单直接）

编辑 `data_warehouse/config.py` 文件，找到以下配置：

```python
DB_USER = os.getenv("DB_USER", "postgres")  # 数据库用户名
DB_PASSWORD = os.getenv("DB_PASSWORD", "")  # 数据库密码（如果为空则不使用密码）
DB_HOST = os.getenv("DB_HOST", "localhost")  # 数据库主机
DB_PORT = os.getenv("DB_PORT", "5432")  # 数据库端口
DB_NAME = os.getenv("DB_NAME", "quantitative_trading")  # 数据库名称
```

**修改示例**（假设你的密码是 `qazwsx`）：

```python
DB_USER = "postgres"        # 数据库用户名
DB_PASSWORD = "qazwsx"      # 数据库密码 ⚠️ 请修改为你的实际密码
DB_HOST = "localhost"       # 数据库主机（通常是localhost）
DB_PORT = "5432"            # 数据库端口（默认5432）
DB_NAME = "quantitative_trading"  # 数据库名称
```

### 方式2: 使用环境变量（推荐，更安全）

#### Windows PowerShell

```powershell
# 设置环境变量（当前会话）
$env:DATABASE_URL = "postgresql://postgres:qazwsx@localhost:5432/quantitative_trading"

# 或分别设置各个参数
$env:DB_USER = "postgres"
$env:DB_PASSWORD = "qazwsx"
$env:DB_HOST = "localhost"
$env:DB_PORT = "5432"
$env:DB_NAME = "quantitative_trading"
```

#### Windows 命令提示符（CMD）

```cmd
set DATABASE_URL=postgresql://postgres:qazwsx@localhost:5432/quantitative_trading
```

#### 永久设置环境变量（Windows）

1. 右键 **"此电脑"** → **"属性"**
2. 点击 **"高级系统设置"**
3. 点击 **"环境变量"**
4. 在 **"用户变量"** 或 **"系统变量"** 中点击 **"新建"**
5. 变量名：`DATABASE_URL`
6. 变量值：`postgresql://postgres:你的密码@localhost:5432/quantitative_trading`
7. 点击 **"确定"** 保存

#### Linux/macOS

```bash
# 临时设置（当前会话）
export DATABASE_URL="postgresql://postgres:qazwsx@localhost:5432/quantitative_trading"

# 永久设置（添加到 ~/.bashrc 或 ~/.zshrc）
echo 'export DATABASE_URL="postgresql://postgres:qazwsx@localhost:5432/quantitative_trading"' >> ~/.bashrc
source ~/.bashrc
```

## 📝 连接URL格式说明

PostgreSQL连接URL格式：

```
postgresql://用户名:密码@主机:端口/数据库名
```

**示例**：

- **有密码**: `postgresql://postgres:qazwsx@localhost:5432/quantitative_trading`
- **无密码**: `postgresql://postgres@localhost:5432/quantitative_trading`
- **自定义端口**: `postgresql://postgres:qazwsx@localhost:5433/quantitative_trading`
- **远程服务器**: `postgresql://postgres:qazwsx@192.168.1.100:5432/quantitative_trading`

## ✅ 测试连接

配置完成后，测试数据库连接：

### 方法1: 使用Python测试

```powershell
# 在项目根目录下
python -c "from data_warehouse.config import DATABASE_URL; print('连接URL:', DATABASE_URL)"

# 测试实际连接
python -c "from sqlalchemy import create_engine; from data_warehouse.config import DATABASE_URL; engine = create_engine(DATABASE_URL); conn = engine.connect(); print('✅ 连接成功！'); conn.close()"
```

### 方法2: 使用psql命令行

```powershell
# 连接到数据库
psql -U postgres -d quantitative_trading

# 或使用完整连接字符串
psql "postgresql://postgres:qazwsx@localhost:5432/quantitative_trading"
```

## 🔒 安全建议

1. **不要将密码提交到Git仓库**
   - 如果使用代码配置，确保 `data_warehouse/config.py` 在 `.gitignore` 中
   - 或使用环境变量方式（更安全）

2. **使用环境变量（推荐）**
   - 密码不会出现在代码中
   - 不同环境可以使用不同配置
   - 更符合最佳实践

3. **密码包含特殊字符**
   - 如果密码包含特殊字符（如 `@`, `:`, `/`），需要进行URL编码
   - 例如：`@` → `%40`, `:` → `%3A`, `/` → `%2F`

## ⚠️ 常见问题

### 问题1: 连接失败 - 密码认证失败

**错误**: `psycopg2.OperationalError: password authentication failed`

**解决**:
1. 检查用户名和密码是否正确
2. 确认PostgreSQL服务正在运行
3. 检查 `pg_hba.conf` 配置

### 问题2: 连接失败 - 数据库不存在

**错误**: `psycopg2.OperationalError: database "quantitative_trading" does not exist`

**解决**:
```powershell
# 创建数据库
psql -U postgres
CREATE DATABASE quantitative_trading;
\q
```

### 问题3: 连接失败 - 无法连接到服务器

**错误**: `psycopg2.OperationalError: could not connect to server`

**解决**:
1. 检查PostgreSQL服务是否运行
2. 检查主机和端口是否正确
3. 检查防火墙设置

### 问题4: 密码包含特殊字符

如果密码包含 `@`, `:`, `/` 等特殊字符，需要进行URL编码：

```python
from urllib.parse import quote_plus

password = "p@ss:w/rd"
encoded_password = quote_plus(password)
DATABASE_URL = f"postgresql://postgres:{encoded_password}@localhost:5432/quantitative_trading"
```
