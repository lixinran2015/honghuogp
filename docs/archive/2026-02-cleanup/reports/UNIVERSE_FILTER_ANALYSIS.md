## 🔍 问题分析

### 1. 数据字段缺失

#### ⚠️ 缺少 `is_st` 字段
```
⚠️ 缺少is_st字段，跳过ST过滤
```
**影响**: 无法过滤ST股票
**解决**: 需要从 `fact_daily_price_qfq` 表获取 `is_st` 字段

#### ⚠️ 缺少价格字段
```
⚠️ 缺少价格字段，跳过低价股过滤
```
**影响**: 无法过滤低价股（<5元）
**解决**: 需要确保数据中有 `close` 或 `currentPrice` 字段

#### ⚠️ 财务数据字段名错误
```
⚠️ 批量获取财务数据失败: column "net_profit_ttm" does not exist
```
**影响**: 无法过滤长期亏损和高负债
**解决**: 检查 `fact_daily_fundamental` 表的实际字段名
