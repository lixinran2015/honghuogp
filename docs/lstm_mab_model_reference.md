# LSTM-MAB 智能评分模型参考文档

> 本文档记录当前 LSTM-MAB 模型的因子构成与技术特点，供后续优化迭代参考。
> 最后更新：2026-04-03

---

## 1. 当前因子列表

### 1.1 默认启用的核心因子（2 个）

当前 `LSTMMABModel` 默认初始化仅启用以下两个因子：

| 因子名称 | 英文标识 | 计算维度说明 |
|----------|----------|--------------|
| **龙头地位** | `leader_position` | 连板高度（40分）+ 空间龙头/刚启动类型（30分）+ 涉及板块数量（20分）+ 在池时间（10分） |
| **技术形态** | `technical` | 20日涨幅 + 强势/震荡/退潮风险标签 + 相对于20日线的位置 |

具体计算逻辑见：
- `backend/api/leaders/leader_tracking.py::_calculate_factor_values()`

### 1.2 架构已支持但未全量启用的扩展因子（2 个）

`EmotionAdaptiveAllocator` 中已配置完整的基础权重，说明模型架构支持以下扩展：

| 因子名称 | 英文标识 | 备注 |
|----------|----------|------|
| **资金流向** | `money_flow` | 情绪周期基础权重已配置，需补充具体计算逻辑 |
| **情绪面** | `sentiment` | 情绪周期基础权重已配置，需补充具体计算逻辑 |

> 若要启用，修改 `LSTMMABModel.__init__()` 中的 `factor_names` 列表即可。

## 2. 模型架构与优点

### 2.1 三层架构

```
┌─────────────────────────────────────────┐
│  LSTM 特征提取器                        │  ← 从历史价格提取时序特征
│  - 预期收益 (expected_return)           │
│  - 不确定性 (uncertainty)               │
└──────────────────┬──────────────────────┘
                   │
┌──────────────────▼──────────────────────┐
│  MAB 动态权重分配器                      │  ← 根据历史表现动态调整因子权重
│  - Thompson Sampling (默认) 或 UCB      │
└──────────────────┬──────────────────────┘
                   │
┌──────────────────▼──────────────────────┐
│  情绪周期自适应层                        │  ← 50% MAB权重 + 50% 情绪基础权重
│  - 支持7种情绪周期配置                   │
└─────────────────────────────────────────┘
```

### 2.2 核心优点

| 优点 | 说明 |
|------|------|
| **时序 + 因子融合** | LSTM 从价格历史中学习时序模式，输出预期收益与不确定性，再与截面因子得分加权融合。 |
| **动态权重学习** | 基于 Thompson Sampling（贝叶斯采样）或 UCB（置信区间），根据因子实际收益表现自动调整权重，避免固定权重在 regimes 变化时失效。 |
| **情绪周期自适应** | `EmotionAdaptiveAllocator` 支持 7 种周期：高涨期、主升期、震荡期、分歧期、低迷期、退潮期、冰点期。不同周期对龙头/技术/资金/情绪的侧重不同。 |
| **可解释输出** | 每只股票输出：总分、等级（S/A/B/C）、各因子得分、各因子权重、预期收益率、置信度。 |
| **持续进化** | 支持 `update_factor_performance()` 根据实际收益更新 MAB；模型可 `save()` / `load()`，实现预测-反馈-迭代的闭环。 |
| **结果稳定性** | `allocate()` 支持传入 `trade_date` 作为随机种子，确保同一交易日内模型输出稳定、可复现。 |

## 4. 已知优化方向（待办）

- [ ] **扩展因子启用**：补充 `money_flow`、`sentiment` 的具体计算逻辑并完成前端展示。
- [ ] **因子数量扩展**：当前仅 2 个核心因子，可考虑增加基本面、量能结构、板块共振等维度。
- [ ] **LSTM 输入特征增强**：目前仅使用 `open/high/low/close/volume` 五列，可融入技术指标（MACD、RSI、布林带等）作为多变量时序输入。
- [ ] **情绪周期自动识别**：当前需外部传入情绪周期，可探索让模型自动从市场数据中推断当前周期。
- [ ] **MAB 奖励函数优化**：当前奖励为 `np.tanh(actual_return * 10)`，可尝试夏普比率、最大回撤惩罚等更精细的奖励设计。
- [ ] **在线学习机制**：目前是批量的 `update()`，可考虑每日自动根据持仓/池内股票的实际收益进行批量反馈更新。
