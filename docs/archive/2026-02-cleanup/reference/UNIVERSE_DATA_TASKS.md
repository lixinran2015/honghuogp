## 📋 任务清单

### ✅ Phase 1: 修正过滤逻辑（容错策略）- 立即执行

**目标**: 让系统先跑起来，缺失数据不直接剔除全部股票

#### 任务1.1: 修改基础过滤器，加入容错
- [ ] 修改 `base_universe_filter()`，缺失字段使用默认值
- [ ] ST字段缺失 → 不过滤（假设都不是ST）
- [ ] 价格字段缺失 → 不过滤（假设都>5元）
- [ ] 财务数据缺失 → 保留股票（避免过度过滤）

#### 任务1.2: 修改S1过滤器，降级条件
- [ ] 临时降级：`roe_ttm > 0`（而不是 > 10%）
- [ ] 临时降级：`pe_ttm < 80`（而不是 < 60）
- [ ] 缺失数据使用 `fillna(0)` 或跳过该条件

#### 任务1.3: 修改S2过滤器，降级条件
- [ ] 临时降级：`turnover_rate > 1%`（而不是 > 1.5%）
- [ ] 临时降级：`close > ma5`（而不是 > ma20，如果ma20缺失）
- [ ] MA20缺失时，跳过趋势判断

#### 任务1.4: 修改S3过滤器，降级条件
- [ ] 临时降级：`turnover_rate > 3%`（而不是 > 5%）
- [ ] 临时降级：`change_pct > 3%`（替代涨停要求）
- [ ] 涨停数据缺失时，使用涨幅替代

**预计时间**: 1-2小时
**优先级**: 🔥 最高

### 📊 Phase 2: 补齐财务数据（S1需要）

**目标**: 补充 `fact_daily_fundamental` 表的财务指标

#### 任务2.1: 检查现有财务数据

- [ ] 确认数据源（Tushare / 东财 / CSV）
- [ ] 评估数据完整性

#### 任务2.2: 补充财务数据ETL
- [ ] 从Tushare获取财务数据（推荐）

- [ ] 或从本地CSV导入（如果有）
- [ ] 写入 `fact_daily_fundamental` 表

**需要字段**:
- `roe_ttm` - ROE TTM
- `gross_margin_ttm` - 毛利率TTM

- `pe_ttm` - PE TTM
- `op_cf_ttm` - 经营现金流TTM

**预计时间**: 2-4小时（取决于数据源）
**优先级**: ⭐ 高

## 🔧 立即执行的修正（Phase 1）

### 1. 修改过滤逻辑，加入容错

**文件**: `backend/services/stock_universe_filter.py`

**修改点**:
- 所有财务数据缺失 → 保留股票（不剔除）
- 所有技术指标缺失 → 跳过该条件
- 使用 `fillna()` 填充缺失值

### 2. 降级过滤条件

**文件**: `backend/config/universe_filter_config.py`

**修改**:
```python
# S1 临时降级版
S1_FILTER_CONFIG = {
    'min_roe': 0.0,              # 从10%降到0%（只要有数据）
    'min_gross_margin': 0.0,     # 从20%降到0%
    'max_pe': 80.0,              # 从60放宽到80
}

# S2 临时降级版
S2_FILTER_CONFIG = {
    'min_amount': 1e8,           # 从3亿降到1亿
    'min_turnover_rate': 1.0,    # 从1.5%降到1.0%

    'min_turnover_rate': 3.0,    # 从5%降到3%
    'require_limit_up': False,   # 不要求涨停
```
