# 9:40 未破分时(≥3%) 监控功能需求文档

## 1. 功能概述

本功能用于监控**距离30日新高5%内**的股票，在指定时间点（如9:40、9:50等）筛选出**未破分时且涨幅≥3%**的股票，并提供结果查看和数据分析功能。

---

## 2. 功能模块

### 2.1 9:40 未破分时(≥3%) 监控页面

#### 2.1.1 页面位置
- 菜单路径：30日新高查询 → 9:40未破分时(≥3%)监控

#### 2.1.2 功能描述
启动监控任务，自动在多个时间点（9:40、9:50、10:00...11:00）执行链式监控，筛选符合条件的股票。

#### 2.1.3 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 交易日期 | date | 当天日期 | 监控的交易日期 |
| 候选输入文件 | text | `near_high_results30-5.txt` | 候选股票列表文件（只读） |
| 截止时间 | text | `09:40:00` | 首次监控的截止时间 |
| 涨幅阈值(%) | number | 3 | 筛选涨幅的最小阈值 |
| 线程数 | select | 8 | 并发线程数（4/8/16） |

#### 2.1.4 业务逻辑

1. **链式执行机制**
   - 监控时间点：09:40:00 → 09:50:00 → 10:00:00 → 10:10:00 → 10:20:00 → 10:30:00 → 10:40:00 → 10:50:00 → 11:00:00
   - 第一轮使用原始输入文件，后续轮次使用上一轮的输出作为输入
   - 逐步筛选，范围递减

2. **时间等待机制**
   - 如果目标日期是**今天**且当前时间早于目标时间点，系统会**自动等待**到目标时间后执行
   - 如果是**历史日期**，立即执行所有时间点

3. **筛选条件**
   - 未破分时：股票在截止时间前未跌破分时均线
   - 涨幅 ≥ 阈值（默认3%）

4. **输出结果**
   - 每个时间点生成独立的结果文件：`{日期}/near_high_results30_{时间}_3pct.txt`
   - 例如：`2025-11-27/near_high_results30_094000_3pct.txt`

#### 2.1.5 状态显示

- **运行中**：显示当前执行的时间点、等待时间
- **完成**：显示找到的股票数量
- **错误**：显示错误信息

#### 2.1.6 操作按钮

| 按钮 | 功能 |
|------|------|
| 开始监控 | 启动监控任务 |
| 下载结果 | 下载最新的监控结果文件（任务完成后显示） |

### 2.2 9:40 监控结果查看页面

#### 2.2.1 页面位置
- 菜单路径：30日新高查询 → 9:40监控结果查看

#### 2.2.2 功能描述
查看指定日期、指定时间点的监控结果，展示股票详细信息表格。

#### 2.2.3 输入参数

| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| 交易日期 | date | 当天日期 | 查询的交易日期 |
| 时间点按钮 | button | - | 选择要查看的时间点 |

#### 2.2.4 时间点选项

提供以下时间点快捷按钮：
- 9点40 (09:40:00)
- 9点50 (09:50:00)
- 10点 (10:00:00)
- 10点10分 (10:10:00)
- 10点20分 (10:20:00)
- 10点30分 (10:30:00)
- 10点40分 (10:40:00)
- 10点50分 (10:50:00)
- 11点 (11:00:00)

#### 2.2.5 数据获取逻辑

1. **优先从数据库获取**
   - 调用 API：`/api/get_monitor_results?date={日期}&time={时间}`
   - 如果数据库有数据，直接使用

2. **降级从文件获取**
   - 如果数据库无数据，调用 `/api/query_stock_info` 从文件查询
   - 文件路径：`{日期}/near_high_results30_{时间}_3pct.txt`

3. **无结果处理**
   - 如果数据库和文件都没有数据，显示"没有符合条件的结果"

#### 2.2.6 结果表格

| 列名 | 说明 | 排序 |
|------|------|------|
| 股票代码 | 6位股票代码 | - |
| 股票名称 | 股票中文名称 | - |
| 今日涨幅(%) | 当日涨跌幅 | ✓ 可排序 |
| 5日涨幅(%) | 5个交易日涨跌幅 | ✓ 可排序 |
| 10日涨幅(%) | 10个交易日涨跌幅 | ✓ 可排序 |
| 金额(万元) | 成交金额 | - |

#### 2.2.7 表格功能

- **颜色标识**：涨幅为正显示红色(#d32f2f)，为负显示绿色(#388e3c)
- **排序功能**：点击列头可按该列升序/降序排序
- **排序指示器**：显示当前排序方向（↑升序 / ↓降序）

## 3. 后端 API 接口

### 3.1 启动监控任务

```
POST /api/run_near5_940
```

**请求参数：**
```json
{
    "date": "2025-11-27",
    "input": "near_high_results30-5.txt",
    "cutoff": "09:40:00",
    "min_change_pct": 3.0,
    "max_workers": 8,
    "chain": true
}
```

**响应：**
```json
{
    "success": true,
    "message": "监控任务已启动"
}
```

### 3.2 获取任务状态

```
GET /api/status/near5_940
```

**响应：**
```json
{
    "running": true,
    "progress": 3,
    "total": 9,
    "message": "执行 10:00:00...",
    "results": ["000001", "000002"],
    "error": null
}
```

### 3.3 获取监控结果

```
GET /api/get_monitor_results?date=2025-11-27&time=09:40:00
```

**响应：**
```json
{
    "success": true,
    "data": [
        {
            "code": "000001",
            "name": "平安银行",
            "pct_today": 2.35,
            "pct_5d": 5.12,
            "pct_10d": 8.76,
            "amount": 12345.67
        }
    ]
}
```

### 3.4 下载结果文件

```
GET /api/download/near5
```

**响应：** 文件下载

| data_date | DATE | 数据日期 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

**唯一约束：** (trade_date, monitor_time, stock_code)

### 4.2 文件存储

- **目录结构：** `{项目根目录}/{日期}/`

## 5. 前端交互流程

### 5.1 监控任务流程

```
用户点击"开始监控"
    ↓
前端调用 POST /api/run_near5_940
    ↓
后端启动后台线程执行链式监控
    ↓
前端每秒轮询 GET /api/status/near5_940
    ↓
显示进度：等待时间 / 当前时间点 / 完成数量
    ↓
任务完成后显示"下载结果"按钮
```

### 5.2 结果查看流程

```
用户选择日期
    ↓
用户点击时间点按钮（如"9点40"）
    ↓
前端调用 GET /api/get_monitor_results
    ↓
如果有数据 → 渲染表格
如果无数据 → 尝试从文件获取
如果仍无数据 → 显示"没有符合条件的结果"
```

## 6. 错误处理

| 场景 | 处理方式 |
|------|----------|
| 任务正在运行中 | 提示"监控任务正在运行中"，禁止重复启动 |
| 执行脚本失败 | 显示错误信息，停止后续时间点执行 |
| 数据库查询失败 | 降级从文件获取 |
| 文件不存在 | 显示"没有符合条件的结果" |
| 网络请求失败 | 显示错误信息 |
