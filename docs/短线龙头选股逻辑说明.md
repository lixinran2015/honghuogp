# 短线龙头选股逻辑说明

> 基于主线雷达（StartupMainlineRadarView）+ 龙头跟踪（LeaderTrackingView）的完整选股链路。
> 文档版本：2026-03-23（v2，11项优化后）

---

## 一、整体流程

```
每日收盘后
    ↓
[step1] 启动候选扫描
    fact_stock_startup_candidate（score ≥ 60，stage = confirmed/started）
    ↓
[step2] 板块强度聚合
    按行业 + 概念聚合信号，计算 strength_score（含趋势项），排出主线 Top10
    ↓
[step3] 龙头快照生成（离线，需手动触发或定时）
    SectorLeaderDetector → fact_sector_leader_snapshot
    ↓
[step4] 主线雷达展示
    每个主线板块的接力链条（空间龙头 → 补涨龙 → 相对强势 → 跟风）
    ↓
[step5] 龙头跟踪池写入
    is_new_leader（刚启动）/ is_space（空间龙头） 写入跟踪池（时效过滤：15个交易日）
    ↓
[step6] 退潮/强势判定（每日实时计算）
    4个退潮信号（加权）→ retreat_label（强势 / 震荡 / 退潮风险）
```

---

## 二、启动候选信号（第一道门）

**数据表**：`fact_stock_startup_candidate`

| 字段 | 筛选条件 | 说明 |
|------|---------|------|
| trade_date | `[start_date, end_date]` | 默认窗口：end_date 往前约10个交易日（14自然日） |
| score | `>= 60` | 系统评分，满分100 |
| stage | `IN ('confirmed', 'started')` | confirmed = 已确认启动；started = 刚启动 |

**score 由启动扫描模块计算，核心维度**（不在本链路，供参考）：
- 均线多头排列
- 成交量放大
- 近期突破前高
- 行业/概念共振

---

## 三、板块强度评分（strength_score）

> **决定哪些板块是主线，以及排名先后**

```python
trend = recent_3d_signals - prev_3d_signals  # 近3日 vs 前3日信号差
strength_score = recent_3d_signals × 2.0 + distinct_stock_count × 0.5 + trend × 1.0
```

| 分量 | 含义 | 权重 |
|------|------|------|
| recent_3d_signals | 窗口内最近3个有信号交易日的信号总数 | 2.0x（最重要） |
| distinct_stock_count | 窗口内触发启动信号的不同股票数（去重） | 0.5x |
| trend | 近3日信号数 − 前3日信号数（升温为正，降温为负） | 1.0x |

**说明**：
- `recent_3d_signals` 衡量近期爆发程度（刚启动的主线分高）
- `distinct_stock_count` 衡量板块宽度（参与的股票越多越主流）
- `trend` 区分"刚刚升温"与"已在降温"的板块，防止排名滞后
- 最终按 strength_score 降序，前端取 Top10 展示

## 四、龙头快照生成（leader_score）

> **决定板块内哪只股票是龙头，以及角色划分**

由 `SectorLeaderDetector` 离线计算，窗口为最近30个交易日（rolling_30d_v2）。

### 4.1 基础指标

| 指标 | 计算方式 |
|------|---------|
| ret_window | `(窗口末收盘 / 窗口首收盘 - 1) × 100`，单位% |
| continuous_limit | 窗口内 `change_pct ≥ 9.5%` 的最大连续天数（近似连板数） |
| avg_amount | 窗口内日均成交额（元） |
| first_start_date | 窗口内首次 `change_pct ≥ 7%` 的日期（启动日） |
| recent_ret_5d | 最近5日涨幅，单位% |
| recent_amount_ratio | 近5日均额 / 前20日均额 |

### 4.2 风险过滤（直接排除）

| 条件 | 阈值 | 说明 |
|------|------|------|
| ST股 | 任意一日为ST | 直接排除 |
| 日均成交额 | `< 1亿元` | 过滤低流动性小票 |
| 窗口数据 | `< 5条日线` | 数据不足，无法评估 |

### 4.3 近期强弱判断（recent_strength）

| 条件 | 结果 |
|------|------|
| 5日涨幅 ≥ 5% **且** 近5日放量 ≥ 1.5倍 | strong（强势） |
| 5日涨幅 ≤ 0% **或** 近5日缩量 ≤ 0.8倍 | weak（走弱） |
| 其他 | neutral（中性） |

### 4.4 leader_score 公式

```
leader_score = 0.40 × score_ret
             + 0.25 × score_limit
             + 0.15 × score_liquidity
             + 0.20 × score_recent
```

各分量均为 0~100 的相对分：

| 分量 | 计算方式 |
|------|---------|
| score_ret | `min(100, ret_window / p75_ret × 100)`，基准为板块内75分位涨幅（至少20%），防止单只妖股压低其他股的得分 |
| score_limit | 连板数映射：0板=40，1板=60，2板=75，≥3板=95 |
| score_liquidity | `avg_amount / 板块最高avg_amount × 100`（板块内相对流动性） |
| score_recent | strong=100，neutral=60，weak=20 |

### 4.5 角色划分规则

**空间龙头（absolute_leader）**：leader_score 板块第一，且同时满足：
- `ret_window ≥ 动态门槛`（= `max(20%, min(40%, 板块中位数涨幅 × 1.5))`，熊市自动降低门槛）
- `continuous_limit ≥ 2` 或 `ret_window ≥ 板块最高涨幅 - 10%`
- `recent_strength ≠ weak`

**补涨龙（catch_up）**：最多认定2只，需同时满足：
- 角色未被占用
- `ret_window ≥ 25%`
- `leader_score ≥ 第一名 × 60%`
- `recent_strength ≠ weak`
- `first_start_date > 空间龙头的启动日`（启动时间更晚）；若龙头无启动日，则要求补涨龙涨幅 < 龙头涨幅（兜底约束）

**相对强势（rel_strength）**：
- `ret_window ≥ 15%` 且 `recent_strength ≠ weak`

**跟风（follower）**：其余全部

## 五、刚启动龙头认定（is_new_leader）

> **主线雷达中标记为"刚启动"的核心判断**

同时满足以下三个条件：

| 条件 | 阈值 | 说明 |
|------|------|------|
| 角色 | absolute_leader 或 catch_up | 相对强势和跟风不算 |
| 30日涨幅 | 25% ≤ ret ≤ 120% | 已有足够空间但未过度拉升 |
| 连板数 | ≤ 3板 | 超过3连板认为进入高位，风险明显增大 |

---

## 六、龙头跟踪池入池条件

> **比主线雷达的"刚启动"判定略宽松，用于扩大跟踪范围**

满足以下任一路径即可入池：

**路径A（直通）**：已被主线雷达认定为 `is_new_leader = True`

**路径B（宽松条件）**：
- 角色：`absolute_leader` 或 `catch_up`
- 连板：`≤ 3板`（与路径A统一）
- 涨幅：`15% ≤ ret ≤ 120%`（下限比路径A更低，门槛更宽）

| 条件 | 主线雷达（is_new_leader） | 跟踪池入池 |
|------|--------------------------|------------|
| 涨幅下限 | 25% | 15% |
| 涨幅上限 | 120% | 120% |
| 连板上限 | 3板 | 3板（或直通） |

**池内字段更新规则**（只升不降）：
- `is_space`（空间龙头）：只从 False → True
- `is_new`（刚启动）：只从 False → True
- `sectors`：取历史所有板块的并集
- `continuous_limit`：取历史最大连板数
- `last_seen_date`：取最晚出现日期

**时效性过滤**：API 返回时过滤 `last_seen_date < trade_date - 21天`（约15个交易日）的历史记录，仅展示近期活跃成员；数据库保留全量历史记录，不删除。

## 七、退潮/强势状态判定

> **持仓中的龙头是否应该继续持有**

基于最近20条日线数据（`fact_daily_price_qfq`）实时计算。

### 7.1 四个退潮信号（加权）

| 信号 | 触发条件 | 权重 |
|------|---------|------|
| 深度回撤 | 从20日高点回落 ≥ 15%，**或**最大回撤 ≥ 20% | **2.0**（单独触发退潮） |
| 跌破20日线（持续） | 近5日中有 ≥ 3日 收盘价 < MA20 | 1.5 |
| 高位放量滞涨 | 曾拉升 ≥ 20%，近5日放量 ≥ 1.5倍，**且**近20日下跌，**且**从高点回落 ≥ 8% | 1.0 |
| 缩量阴跌 | 近5日缩量 ≤ 0.7倍，**且**近20日下跌 | 0.5 |

### 7.2 强势判定条件（三选一）

| 条件 | 含义 |
|------|------|
| `close ≥ MA20 × 1.03` | 收盘站稳20日线上方超3% |
| `close ≈ 20日最高价`（误差 < 0.01%）| 处于20日高点 |
| `近20日涨幅 > 10%` 且 `近5日成交量不萎缩` | 趋势强势且量能配合 |

### 7.3 最终标签

| 加权退潮分 | 强势特征 | 标签 |
|-----------|---------|------|
| ≥ 2.0 | 任意 | **退潮风险**（建议减仓或清仓） |
| 0（无信号） | 有 | **强势**（可持有或加仓） |
| 其他 | — | **震荡**（观望，不加仓） |

> 注：深度回撤（权重2.0）单独即可触发退潮风险；跌破20日线（1.5）+ 缩量阴跌（0.5）合计也可触发。

## 八、选股决策框架

### 买入条件（同时满足）

1. **板块主线**：所属板块 strength_score 排名前5，且 `trend ≥ 0`（近3日信号不弱于前3日）
2. **角色**：空间龙头或补涨龙（`absolute_leader` / `catch_up`）
3. **刚启动**：`is_new_leader = True`（30日涨幅25%~120%，连板≤3）
4. **近期不弱**：`recent_strength ≠ weak`（近5日未见明显走弱）
5. **状态**：`retreat_label = "强势"` 或 `"震荡"`（非退潮风险）
6. **流动性**：日均成交额 ≥ 1亿元

### 回避条件（有任一则不买）

- `retreat_label = "退潮风险"`（加权退潮分 ≥ 2.0）
- `continuous_limit > 3`（高位连板妖股，风险明显增大）
- `30日涨幅 > 120%`（过度拉升，风险极高）
- ST股、日均成交额 < 1亿

### 持仓管理

| 状态 | 建议 |
|------|------|
| 强势 | 持有，可分批加仓 |
| 震荡 | 持有观望，不加仓 |
| 退潮风险 | 减仓或清仓；退潮分 ≥ 3.5（深回撤+跌破MA20）时立即清仓 |

## 九、数据依赖关系

```
fact_stock_startup_candidate    ← 启动扫描（每日盘后）
    ↓
StartupSectorAnalyzer.analyze() ← 实时 API 调用
    ↓ 读取
fact_sector_leader_snapshot     ← SectorLeaderDetector（每日盘后，或手动重建）
    ↓
fact_leader_tracking_pool       ← DB表，每次API调用增量写入
    ↓ 读取
fact_daily_price_qfq            ← 行情数据（退潮计算）
```

**时效说明**：
- `startup_candidate`：每日收盘后扫描，当日可用
- `sector_leader_snapshot`：需手动触发"重建板块龙头(v2)"，或设定定时任务
- `leader_tracking_pool`：API 调用时实时增量写入 DB，时效过滤21自然日
- 退潮状态：API 调用时实时计算，无缓存

## 十、关键参数快查

| 参数 | 当前值 | 说明 |
|------|--------|------|
| 启动信号最低分 | 60 | min_score，可通过前端调整 |

| 龙头快照窗口 | 30个交易日 | rolling_30d_v2 |
| 日均成交额门槛 | 1亿元 | liquidity_ok |

| 补涨龙最低涨幅 | 25% | ret_window 门槛 |
| score_ret 基准 | 板块内75分位涨幅（至少20%） | 防妖股扭曲评分 |
| 刚启动涨幅区间 | 25%~120% | is_new_leader |
| 连板上限（is_new_leader） | ≤ 3板 | 超过3板视为高位 |
| 连板上限（跟踪池路径B） | ≤ 3板 | 与 is_new_leader 统一 |

| 退潮加权分阈值 | ≥ 2.0 | 触发"退潮风险"标签 |
| 深度回撤阈值 | 从高点 -15% 或最大回撤 -20% | 权重2.0，单独触发 |
| strength_score 趋势项 | trend = recent_3d − prev_3d | 权重1.0，区分升温/降温 |
