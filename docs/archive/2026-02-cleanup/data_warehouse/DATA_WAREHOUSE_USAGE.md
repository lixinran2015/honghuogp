# 数据仓库使用说明

## 当前状态

✅ **PostgreSQL数据仓库已集成到后端服务**

`MarketDataService` 现在会：
1. **优先从PostgreSQL数据仓库读取数据**
2. 如果数据仓库数据不足（少于100只股票），自动回退到实时查询
3. 如果实时查询失败，再次尝试从数据仓库读取（备用）

## 数据状态

当前数据仓库中有：
- **股票维表**：5166 只股票 ✅
- **日线数据**：726 条（3只股票，1年数据）⚠️ **样本数据**
- **财务数据**：0 条（待回补）

## 如何在前端看到完整效果

### 方案1：回补更多股票数据（推荐）

```bash
# 回补前100只股票的历史数据（1年）
python -m data_warehouse.etl.backfill_batch --limit 100 --start 2024-01-01

# 或者回补更多股票
python -m data_warehouse.etl.backfill_batch --limit 500 --start 2024-01-01
```

### 方案2：运行每日增量更新

```bash
# 更新今天的日线数据（会更新所有在维表中的股票）
python -m data_warehouse.etl.daily_update --prices-only
```

### 方案3：使用实时查询（当前默认行为）

如果数据仓库数据不足（少于100只），系统会自动回退到实时查询，所以前端仍然可以正常显示推荐股票。

## 推荐操作

1. **立即回补数据**（让前端看到完整效果）：
   ```bash
   python -m data_warehouse.etl.backfill_batch --limit 200 --start 2024-11-01
   ```

2. **设置每日自动更新**：
   ```bash
   # 使用cron或调度服务
   python -m data_warehouse.etl.scheduler --daemon
   ```

3. **查看前端效果**：
   - 访问前端页面
   - 点击"📦 数据仓库"查看数据统计
   - 点击"🔄 智能选股"查看推荐（会优先使用数据仓库数据）

## 注意事项

- 如果数据仓库数据少于100只，系统会自动回退到实时查询
- 数据仓库数据超过3天时，也会尝试实时查询获取最新数据
- 实时查询失败时，会使用数据仓库的数据作为备用
