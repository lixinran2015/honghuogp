# 推荐池前端页面使用指南

## 📍 访问路径

```
http://localhost:5173/recommendation-pool
```

或点击导航菜单：**💎 推荐池**

---

## 🎨 页面布局

### 1. 顶部统计区域

显示实时统计信息：
- **总推荐**：最近N天的推荐总数
- **活跃中**：状态为active的推荐数
- **平均分**：推荐股票的平均启动得分

### 2. 控制面板

**筛选条件**：
- **查询天数**：查询最近N天的推荐（1-90天）
- **状态**：全部/活跃中/已关闭
- **信号强度**：全部/强/中/弱
- **最低得分**：筛选得分≥N的推荐（60-100）

**操作按钮**：
- **🔍 查询**：根据筛选条件加载推荐列表
- **🔄 刷新推荐**：扫描完全启动股票，生成新推荐

### 3. 推荐列表表格

**列说明**：

| 列名 | 说明 | 可排序 |
|------|------|--------|
| 推荐日期 | 股票加入推荐池的日期 | ✅ |
| 代码/名称 | 股票代码和名称 | ✅ |
| 信号强度 | 强/中/弱，颜色区分 | ✅ |
| 得分 | 启动得分（60-100分） | ✅ |
| 推荐标签 | 最多显示3个标签 | ❌ |
| 入选价 | 推荐时的股价 | ✅ |
| 当前价 | 当前股价（待实时更新） | ✅ |
| 涨幅 | 入选至今的涨跌幅 | ✅ |
| 风险 | 低/中/高，颜色区分 | ❌ |
| 操作 | 查看详情/关闭推荐 | ❌ |

**颜色说明**：
- 🔴 **红色**：强信号、涨幅为正
- 🟡 **黄色**：中信号、中等风险
- 🟢 **绿色**：低风险
- ⚫ **灰色**：弱信号、跌幅

## 🔧 功能使用

### 功能1：查询推荐

1. 设置筛选条件（天数、状态、信号强度、最低得分）
2. 点击"🔍 查询"按钮
3. 查看推荐列表

**示例**：
```
查询天数: 30
状态: 活跃中
信号强度: 强
最低得分: 80
→ 点击"查询"
→ 显示最近30天、活跃状态、强信号、得分≥80的推荐
```

### 功能2：刷新推荐

**用途**：扫描所有完全启动的股票，生成新推荐

**步骤**：
1. 点击"🔄 刷新推荐"按钮
2. 确认操作
3. 等待扫描完成（可能需要几秒）
4. 查看结果提示："刷新完成: 新增X只，跳过Y只"
5. 列表自动刷新

**注意**：
- 刷新会扫描所有未推荐的完全启动股票
- 已推荐的股票不会重复推荐
- 建议每日收盘后执行一次

### 功能3：查看详情

**步骤**：
1. 点击推荐列表中的"📄"图标
2. 弹出详情模态框

**详情内容**：
- **基本信息**：得分、信号强度、入选价、涨幅
- **推荐标签**：所有标签展示
- **推荐原因**：完整的推荐理由（多行文本）
- **风险提示**：风险等级和风险说明

**示例**：
```
推荐原因预览：

**强烈推荐**（启动得分：95分）

1. ✅ **短期均线金叉**，启动信号明确
2. 📈 MACD金叉，动能转强
3. 📊 KDJ(65)处于强势区间
4. 📐 均线呈多头排列，趋势向上
5. 💰 成交额12.5亿（量比2.3x），放量明显
6. 🎯 突破60日高点，强势创新高
```

### 功能4：关闭推荐

**用途**：将不再关注的推荐标记为已关闭

**步骤**：
1. 点击推荐列表中的"❌"图标
2. 确认操作
3. 推荐状态变更为"已关闭"

**注意**：
- 关闭后的推荐不会在"活跃中"筛选中显示
- 可通过状态筛选为"已关闭"查看历史记录
- 关闭操作不可撤销

### 功能5：排序

**可排序列**：
- 推荐日期
- 代码/名称
- 信号强度
- 得分
- 入选价
- 当前价
- 涨幅

**操作**：
- 点击列标题进行排序
- 再次点击切换升序/降序
- 显示排序图标：↓（降序）↑（升序）

## 🐛 常见问题

**Q: 为什么推荐列表为空？**
A: 可能原因：
- 筛选条件过于严格
- 最近没有完全启动的股票
- 需要点击"刷新推荐"生成新推荐

**Q: 刷新推荐后没有新增？**
A: 可能原因：
- 所有完全启动的股票已推荐
- 当前市场没有符合条件的股票
- 建议降低最低得分查看更多推荐

**Q: 推荐详情中的推荐原因很长？**
A: 这是正常的，详细的推荐原因包括：
- 主要信号
- 技术指标支持
- 量能表现
- 趋势判断

**Q: 如何批量关闭推荐？**
A: 目前暂不支持批量操作，需逐个关闭
- 后续版本将支持多选批量操作
