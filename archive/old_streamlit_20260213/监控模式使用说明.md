# 监控模式使用说明

## 🎯 新功能概述

程序现在支持**首次筛选 + 持续监控**模式：

1. **首次运行**：筛选所有创业板+科创板股票，保存符合条件的股票
2. **后续运行**：每5分钟检查一次已保存的股票，自动更新列表
3. **自动循环**：无需手动重复运行，自动定时监控

## 📋 工作流程

### 第一次运行

```
1. 检测到没有 filtered_stocks.txt 文件
   ↓
2. 首次筛选模式：扫描所有创业板+科创板股票（~2000只）
   ↓
3. 筛选出符合条件的股票（例如：20只）
   ↓
4. 保存到 filtered_stocks.txt
   ↓
5. 等待5分钟后，自动进入监控模式
```

### 后续运行（监控模式）

```
1. 检测到 filtered_stocks.txt 文件存在
   ↓
2. 加载已保存的股票列表（例如：20只）
   ↓
3. 检查这20只股票是否仍符合条件
   ↓
4. 更新列表（移除不符合条件的）
   ↓
5. 保存更新后的列表
   ↓
6. 等待5分钟，重复步骤2-5
```

## 💡 使用场景

### 场景1：盘中监控强势股

**目的**：找到并持续跟踪盘中强势股

**步骤**：
1. 9:40后首次运行，筛选出符合条件的股票
2. 程序每5分钟自动检查一次
3. 实时了解哪些股票仍保持强势
4. 如果股票破均线，自动从列表移除

### 场景2：次日复盘使用

**目的**：次日继续监控前一天筛选的强势股

**步骤**：
1. 运行程序（自动读取昨天的列表）
2. 检查这些股票今天是否仍然强势
3. 持续监控，发现持续强势的股票

### 场景3：重新筛选

**目的**：重新筛选所有股票

**步骤**：
1. 删除 `filtered_stocks.txt` 文件
2. 重新运行程序
3. 程序将进行首次筛选

## 🔧 配置参数

### 监控间隔

在 `fenshi.py` 第 497 行：

```python
monitor_interval = 5 * 60  # 监控间隔（秒），默认5分钟
```

**可选值**：
- `1 * 60`：1分钟（快速监控）
- `3 * 60`：3分钟（平衡）
- `5 * 60`：5分钟（推荐）✅
- `10 * 60`：10分钟（较慢）
- `15 * 60`：15分钟（慢速监控）

### 存储文件名

在 `fenshi.py` 第 498 行：

```python
filtered_file = "filtered_stocks.txt"  # 存储文件名
```

可以自定义文件名，例如：
- `"filtered_stocks_20251031.txt"`：按日期
- `"my_watchlist.txt"`：自定义名称

## 📁 存储文件格式

`filtered_stocks.txt` 内容示例：

```json
{
  "date": "2025-10-31 10:15:23",
  "stocks": [
    "sz.300001",
    "sz.300002",
    "sh.688001",
    "sh.688002"
  ]
}
```

**字段说明**：
- `date`：保存时间
- `stocks`：股票代码列表

## ⚙️ 常见操作

**方法**：按 `Ctrl+C`

### 2. 重新进行首次筛选

**方法**：删除 `filtered_stocks.txt` 文件，然后重新运行


**Linux/Mac**：

```bash
rm filtered_stocks.txt
```

## 💡 使用建议

### 1. 首次筛选时机

**推荐**：9:40 之后
- 原因：筛选条件包含"9:40涨幅≥2%"
- 在9:40之前运行会筛选不到任何股票

### 2. 监控间隔设置

**推荐**：5分钟
- 太短（1-2分钟）：频繁请求，可能被限流
- 太长（>10分钟）：反应不及时
- 5分钟：平衡实时性和稳定性

### 3. 盘中使用

**建议**：
```
9:40  首次运行，筛选强势股
9:45  第1次监控
9:50  第2次监控
...
15:00 最后一次监控
```

### 4. 次日使用

**方案1**：保留昨天的列表
- 直接运行，监控昨天的强势股
- 了解持续性

**方案2**：重新筛选
- 删除 `filtered_stocks.txt`
- 重新运行，找到今天的强势股

## ⚠️ 注意事项

### 1. 文件冲突

如果同时运行多个程序实例：
- 会共享同一个 `filtered_stocks.txt`
- 可能导致数据覆盖
- 建议：使用不同的文件名

### 2. 网络稳定性

监控模式需要持续网络连接：
- baostock 服务器可能不稳定
- 网络中断会导致检查失败
- 程序会自动重试，但可能影响结果

### 3. 数据更新延迟

baostock 数据更新有延迟：
- 通常延迟3-5分钟
- 实时性要求高的场景需注意
- 建议结合其他实时行情软件使用

### 4. 长时间运行

程序设计为持续运行：
- 确保电脑不休眠
- 确保网络连接稳定
- 可设置定时任务，交易日自动运行
