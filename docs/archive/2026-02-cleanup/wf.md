从**量化角度**筛选财务良好的公司，核心是**将财务判断转化为「可赋值、可筛选、有明确阈值、能批量回测」的指标规则**，摒弃定性分析的模糊性，同时遵循**「先排雷（剔除高风险）→ 再选优（筛选核心优质指标）→ 最后交叉验证（避免单一指标失真）」**的层级逻辑。

量化筛选的关键是**区分通用阈值（全行业基础标准）+ 行业分位数（对标行业，避免跨行业生搬硬套）**，同时兼顾**时间连续性（看连续3-5期数据，避免单期指标失真）**，以下整理**可直接落地的量化指标体系**，包含**排雷指标、核心优质指标**（分通用阈值/成熟企业/上升期企业）、**量化筛选层级**、**落地公式示例**和**避坑要点**，适配Python/Tushare/通达信/同花顺等量化工具，可直接嵌入选股策略。

### 核心前提：量化筛选的3个基础规则
1. **数据口径**：统一用**合并报表+扣非后数据**（剔除母公司数据、非经常性收益，避免利润造假/报表粉饰）；
2. **时间维度**：看**连续3-5个报告期（季度/年度）**，单期指标达标无意义，**持续达标才是财务良好的核心**；
3. **行业标准化**：所有指标均需对标**申万一级/二级行业的中位数/75分位**（如重资产行业资产负债率60%是合理，轻资产行业60%就是高杠杆，必须行业内对比）。

## 一、第一层级：量化排雷指标（基础筛选，直接剔除高风险公司）
量化的第一步是**先把财务爆雷的公司筛掉**，这是财务良好的**底线**，指标均为**「一票否决项」**，只要有1项不达标，直接剔除，无需进入后续筛选。
| 量化排雷指标 | 计算公式 | 全行业通用否决阈值 | 量化意义 |
|--------------|----------|--------------------|----------|
| ST/退市风险 | 财报标注 | 含ST/*ST/退市预警/其他风险警示 | 剔除交易层面的高风险标的 |
| 资不抵债风险 | 净资产=总资产-总负债 | 净资产≤0（资不抵债） | 公司账面资产不足以覆盖负债，破产风险极高 |
| 持续亏损风险 | 扣非归母净利润 | 连续2个会计年度扣非归母净利润≤0 | 主业持续亏钱，财务基本面已恶化 |
| 现金流断裂风险 | 经营活动现金流净额 | **上升期行业**：连续3期≤0 且 营收增长<10%；**其他行业**：连续2期≤0 | 主业赚不到现金，但上升期行业可容忍阶段性负现金流（需营收增长支撑） |
| 商誉减值风险 | 商誉/净资产 | 商誉/净资产>30% | 商誉占比过高，减值风险大 |
| 关联交易风险 | 关联交易/营收 | 关联交易/营收>20% | 关联交易占比过高，独立性存疑 |
| 大股东质押风险 | 大股东质押率 | 质押率>60% | 控制权风险高，可能引发平仓 |
| 利息偿付风险 | 利息保障倍数=EBIT/利息费用（EBIT=营业利润+财务费用） | 利息保障倍数<2 且 连续2期下降 | 赚的钱连利息都覆盖不了，债务违约风险高 |
| 审计意见风险 | 财报审计意见 | 非“标准无保留意见”（如带强调事项/保留/否定/无法表示） | 审计机构对财报真实性存疑，大概率有财务问题 |

**量化筛选逻辑**：以上指标**全部达标（无否决项）**，才能进入下一层级核心指标筛选。

## 二、第二层级：核心优质量化指标（分维度定阈值，可直接赋值筛选）
这是判断**财务良好**的核心，分**现金流（核心）、盈利质量、成长性、偿债能力、运营效率**5大维度，每个维度给出**全行业通用基础阈值**+**成熟企业强化阈值**+**上升期企业适配阈值**，同时标注**量化筛选权重**（权重越高，对财务良好的影响越大），可根据选股风格（价值/成长）调整权重。

### 注：所有指标要求「连续3期达标」，且**指标值≥行业中位数**（标★为「核心必选」，权重最高）
| 维度 | 量化指标（★核心必选） | 计算公式 | 全行业通用基础阈值 | 成熟企业强化阈值 | 上升期企业适配阈值 | 量化权重 | 行业对标要点 |
|------|----------------------|----------|--------------------|--------------------|--------------------|----------|--------------|
| 现金流（★权重最高，现金为王） | ★经营活动现金流净额 | 财报直接取数（扣非） | 连续3期>0 | 连续3期>0 且 同比增速≥10% | 连续3期>0 且 环比增速≥5% | 30% | 全行业通用，无例外 |
|      | ★净现比=经营现金流净额/扣非归母净利润 | 经营现金流净额÷扣非归母净利润 | ≥动态阈值（见下表） | ≥1.0 | ≥动态阈值（见下表） | 25% | **根据行业周期动态调整**（上升期0.4-0.5，成熟期0.6-0.9，下滑期0.9-1.0） |
|      | 收现比=经营现金流净额/营业收入 | 经营现金流净额÷营业收入 | ≥动态阈值（见下表） | ≥0.8 | ≥动态阈值（见下表） | 20% | **根据行业周期动态调整**（上升期0.5-0.6，成熟期0.7-0.9，下滑期0.8-0.9） |
| 盈利质量（★利润扎实，无水分） | ★扣非利润占比=扣非归母净利润/归母净利润 | 扣非归母净利润÷归母净利润 | ≥0.8 且 连续3期不下降 | ≥0.9 | ≥0.8 | 25% | 比值越接近1，利润越真实 |
|      | ★销售毛利率（扣非） | （营收-营业成本）÷营收×100% | ≥行业中位数 且 连续3期不下降 | ≥行业75分位 且 同比≥0 | ≥行业中位数 且 单期下降≤5% | 20% | 科技/医药≥30%，制造/商贸≥15% |
|      | ★扣非ROE=扣非归母净利润/平均净资产×100% | 扣非归母净利润÷[(期初净资产+期末净资产)/2] | ≥行业中位数 | ≥12% 且 ≥行业75分位 | ≥8% 且 连续3期提升 | 30% | 价值股核心指标，成长股看“持续提升” |
|      | 销售净利率（扣非） | 扣非归母净利润÷营收×100% | ≥行业中位数 且 连续3期不下降 | ≥行业75分位 | ≥行业中位数 且 环比改善 | 15% | 辅助指标，配合ROE使用 |
| 成长性（盈利/营收可持续增长） | ★营收同比增长率（扣非） | （本期营收-上年同期营收）÷上年同期营收×100% | ≥0 且 ≥行业中位数 | ≥10% | ≥20% | 20% | 成长股核心，价值股看“稳增长” |
|      | ★扣非净利润同比增长率 | （本期扣非利润-上年同期扣非利润）÷上年同期扣非利润×100% | ≥0 且 ≥行业中位数 | ≥15% | ≥0% 或 环比提升≥10% | 25% | 成长股可容忍单期负增长，但必须环比收窄 |
| 偿债能力（杠杆可控，无偿债压力） | ★流动比率 | 流动资产÷流动负债 | ≥1.2 且 ≥行业中位数 | ≥1.5 | ≥1.2 | 15% | 金融行业除外，轻资产行业可略低 |
|      | ★速动比率=（流动资产-存货）÷流动负债 | （流动资产-存货）÷流动负债 | ≥0.8 且 ≥行业中位数 | ≥1.0 | ≥0.8 | 15% | 存货占比高的行业（制造业/消费）重点看 |
|      | 资产负债率 | 总负债÷总资产×100% | ≤行业75分位 | ≤60%（全行业） | ≤行业75分位 且 负债增速≤营收增速 | 10% | 重资产（制造/基建）≤70%，轻资产（科技/服务）≤50% |
| 运营效率（资产周转快，无资金闲置） | ★应收账款周转率 | 营收÷平均应收账款余额 | ≥行业中位数 且 连续3期不下降 | ≥行业75分位 | ≥行业中位数 | 15% | 商贸/制造业重点看，避免赊销占款 |
|      | ★存货周转率 | 营业成本÷平均存货余额 | ≥行业中位数 且 连续3期不下降 | ≥行业75分位 | ≥行业中位数 且 存货增速≤营收增速 | 15% | 消费/制造业重点看，避免库存积压 |
|      | 总资产周转率 | 营收÷平均总资产余额 | ≥行业中位数 且 连续3期不下降 | ≥行业75分位 | ≥行业中位数 且 持续提升 | 10% | 反映整体资产运营效率，辅助指标 |

### 行业周期净现比阈值参考表（2025Q1）

| 行业周期 | 行业示例 | 净现比阈值 | 收现比阈值 | 说明 |
|---------|---------|-----------|-----------|------|
| **上升期** | 人工智能、新能源、半导体、生物医药、消费电子、军工 | 0.4-0.6 | 0.5-0.7 | 快速扩张期，容忍赊销，但需关注回款质量。上升期行业且营收增长>20%时，可进一步放宽10% |
| **成熟期** | 消费、医药、银行、公用事业、交通运输 | 0.6-0.9 | 0.7-0.9 | 行业格局稳定，现金流健康。消费/医药等现款现货行业要求更高（0.8-0.9） |
| **下滑期** | 房地产、传统零售、教育培训、传统制造、传媒 | 0.9-1.0 | 0.8-0.9 | 必须现金流为正，高杠杆风险。房地产、教育等高风险行业要求净现比≥1.0 |

**注意**：
- 阈值应根据行业分位数动态调整，而非固定值
- 同一行业内部可能分化（如新能源中光伏和储能表现不同）
- 季度更新行业周期判断，月度微调阈值
- 详细配置见 `config/industry_cash_ratio_thresholds.yaml`
- 使用 `IndustryCycleService` 服务类获取动态阈值

### 量化赋值技巧
可将每个达标指标赋值**1分**，未达标赋值**0分**，核心指标（标★）双倍赋值**2分**，按**总分/满分≥80%** 筛选，同时要求**各维度至少80%指标达标**（避免单维度拉满，其他维度拉胯）。

## 三、第三层级：量化交叉验证（避免单一指标失真，剔除"伪财务良好"公司）
量化筛选的关键是**「指标联动验证」**，单一指标达标不代表财务良好，需通过**反向条件筛选**剔除"指标矛盾"的公司，以下为**必选的交叉验证规则**，同样为**一票否决项**：

**注意**：以下规则中的阈值应根据行业周期动态调整，详见行业周期净现比阈值参考表。

1. 营收同比增长率≥20% **但** 收现比<动态阈值（上升期0.5，其他0.6） → 剔除（营收虚增，靠赊销/降价撑增长，无现金支撑）；

2. 扣非ROE≥15% **但** 净现比<动态阈值（上升期0.4，成熟期0.6，下滑期0.9） → 剔除（账面盈利高，实际没现金，利润造假嫌疑）；

3. **主动加杠杆**（资产负债率同比提升≥10% **且** 有息负债增速>营收增速） **但** 营收同比增长率<5% → 剔除（加杠杆未转化为增长，盲目举债）；
   **注意**：如果资产负债率提升是由于权益融资（增发、可转债转股）导致，不触发此规则；

4. 毛利率同比下降≥10% **但** 营收同比增长率<10% → 剔除（盈利壁垒丧失，且增长乏力，赔本赚吆喝）；

5. **被动库存积压**（存货周转率同比下降≥20% **且** 存货同比增速≥30% **且** 营收同比增长率<5%） → 剔除（库存积压，现金流被占用，面临跌价损失）；
   **注意**：如果存货增长伴随营收增长>10%，可能是主动备货，不触发此规则。

## 四、可直接落地的量化筛选层级（适配所有量化工具）
将以上指标整合为**「三层递进式筛选逻辑」**，可直接写入Python/Tushare/通达信公式，**从宽到严，逐步缩容**，示例如下（以**季度数据+连续3期**为时间维度）：
### 第一层：基础排雷（全部满足，否则剔除）
```
ST/退市风险=0 且 净资产>0 且 连续2期扣非净利润>0 且 连续2期经营现金流>0 且 利息保障倍数≥2 且 审计意见=标准无保留
```
### 第二层：核心指标达标（★核心指标全部满足，非核心指标≥80%满足，且均≥行业中位数）
```
连续3期经营现金流>0 且 连续3期净现比≥动态阈值（根据行业周期） 且 连续3期扣非利润占比≥0.8 且 连续3期扣非ROE≥行业中位数 且 连续3期营收同比≥0 且 连续3期流动比率≥1.2 且 连续3期应收账款周转率≥行业中位数
```

**动态阈值获取方法**：
- Python代码：使用 `IndustryCycleService.get_net_cash_ratio_threshold(industry_name, revenue_growth)` 获取
- 配置文件：参考 `config/industry_cash_ratio_thresholds.yaml`
- 文档参考：见上方"行业周期净现比阈值参考表"
### 第三层：交叉验证（无任何一项触发，否则剔除）
```
(营收同比<20% 或 收现比≥动态阈值) 且 (扣非ROE<15% 或 净现比≥动态阈值) 且 (主动加杠杆且营收同比<5% 或 非主动加杠杆 或 营收同比≥5%) 且 (毛利率同比下降<10% 或 营收同比≥10%) 且 (被动库存积压 或 非被动库存积压)
```

**动态阈值说明**：
- 收现比阈值：上升期0.5，其他0.6
- 净现比阈值：上升期0.4，成熟期0.6，下滑期0.9
- 主动加杠杆：资产负债率同比提升≥10% 且 有息负债增速>营收增速
- 被动库存积压：存货周转率同比下降≥20% 且 存货同比增速≥30% 且 营收同比增长率<5%

## 五、量化落地示例（Python+Tushare伪代码，可直接复制修改）
以**筛选申万医药生物行业的财务良好公司**为例，用Tushare取数，实现以上量化逻辑，核心是**按行业分位数筛选+连续期数判断**：
```python
import tushare as ts
import pandas as pd
import numpy as np

# 1. 初始化Tushare
ts.set_token('你的TOKEN')
pro = ts.pro_api()

# 2. 获取申万医药生物行业股票列表（申万一级行业代码801150）
stock_basic = pro.stock_basic(exchange='', list_status='L', fields='ts_code,symbol,name,industry')
pharm_stock = stock_basic[stock_basic['industry']=='医药生物']['ts_code'].tolist()

# 3. 定义取数函数（获取连续3期季度财务数据）
def get_fin_data(ts_code):
    # 取财务指标（fina_indicator）+ 利润表（profit_data）+ 现金流量表（cashflow_data）
    fina = pro.fina_indicator(ts_code=ts_code, start_date='20230101', end_date='20241231', freq='Q')
    profit = pro.profit_data(ts_code=ts_code, start_date='20230101', end_date='20241231', freq='Q')
    cash = pro.cashflow_data(ts_code=ts_code, start_date='20230101', end_date='20241231', freq='Q')
    # 合并数据，按报告期倒序
    df = pd.merge(pd.merge(fina, profit, on=['ts_code','end_date']), cash, on=['ts_code','end_date'])
    df = df.sort_values('end_date', ascending=False).head(3)  # 取最近3期
    return df

# 4. 定义量化筛选函数（使用动态阈值）
def filter_fin_good(ts_code):
    try:
        df = get_fin_data(ts_code)
        if df.shape[0]<3: return False  # 数据不足3期，剔除
        
        # 导入行业周期服务
        try:
            from backend.services.industry.industry_cycle_service import IndustryCycleService
            industry_cycle_service = IndustryCycleService()
        except:
            industry_cycle_service = None
        
        # 获取行业名称
        stock_info = pro.stock_basic(ts_code=ts_code, fields='ts_code,industry')
        industry_name = stock_info.iloc[0]['industry'] if not stock_info.empty else ''
        
        # 排雷指标
        if (df['roe'].isna()).any() or (df['profit_parent'].sum()<=0): return False  # 净资产/扣非利润为负
        
        # 现金流断裂风险（上升期行业放宽）
        is_rising = industry_cycle_service.is_rising_industry(industry_name) if industry_cycle_service else False
        revenue_growth = df['tr_yoy'].mean() if 'tr_yoy' in df.columns else 0
        
        if is_rising and revenue_growth < 10:
            # 上升期行业：连续3期≤0 且 营收增长<10% 才剔除
            if (df['ocf'] <= 0).sum() >= 3:
                return False
        else:
            # 其他行业：连续2期≤0 就剔除
            if (df['ocf'] <= 0).sum() >= 2:
                return False
        
        # 核心指标（连续3期达标）
        net_cash_ratio = df['ocf']/df['profit_parent']  # 净现比
        
        # 获取动态阈值
        if industry_cycle_service:
            threshold = industry_cycle_service.get_net_cash_ratio_threshold(industry_name, revenue_growth)
        else:
            threshold = 0.6  # 默认阈值
        
        if (net_cash_ratio < threshold).any(): 
            return False  # 净现比不达标
        
        non_oper_ratio = df['profit_dedt']/df['profit_parent']  # 扣非利润占比
        if (non_oper_ratio < 0.8).any(): return False
        
        if (df['tr_yoy'] < 0).any(): return False  # 营收同比≥0
        return True
    except:
        return False

# 5. 批量筛选
good_stock = [code for code in pharm_stock if filter_fin_good(code)]
print('医药生物行业财务良好的股票：', good_stock)
```

## 六、量化筛选的关键避坑要点（决定筛选结果的准确性）
1. **避免跨行业筛选**：必须按**申万二级行业**分组（如白酒属于饮料制造，不能和医药一起筛选），所有指标阈值均为**行业内分位数**，而非全行业固定值；
2. **剔除次新股/财报数据不全的公司**：上市时间不足1年的公司，财务数据不完整，连续期数无法判断，直接剔除；
3. **区分财报频率**：**年度数据**适合价值股筛选，**季度数据**适合成长股/中短期选股，避免用单年度数据筛选短期标的；
4. **数据清洗**：剔除**指标为0/NaN/无限大**的异常值（如营收为0、净现比无限大），避免量化公式报错；
5. **动态调整阈值**：
   - **行业周期差异化**：根据行业周期（上升期/成熟期/下滑期）动态调整净现比和收现比阈值，详见"行业周期净现比阈值参考表"
   - **市场环境调整**：牛市可适当放宽阈值，熊市收紧阈值，适配市场环境
   - **使用服务类**：推荐使用 `IndustryCycleService` 服务类获取动态阈值，而非硬编码固定值
6. **行业周期判断**：季度更新行业周期判断，月度微调阈值，详见 `docs/行业周期判断_2025Q1.md`

## 七、不同选股风格的量化指标权重调整
可根据**价值型/成长型/稳健型**选股风格，调整核心指标的权重，让筛选更精准：
| 选股风格 | 核心权重方向 | 指标权重调整 |
|----------|--------------|--------------|
| 价值型（成熟白马） | 盈利质量+现金流+偿债能力 | 扣非ROE（40%）+ 净现比（30%）+ 资产负债率（15%） |
| 成长型（上升期优质公司） | 成长性+现金流+运营效率 | 营收同比（30%）+ 扣非净利润同比（25%）+ 经营现金流（20%） |
| 稳健型（低波动防御） | 现金流+盈利稳定性+运营效率 | 经营现金流（35%）+ 毛利率（25%）+ 应收账款周转率（20%） |

### 最后一句话总结
量化角度的“财务良好”，本质是**「连续3期以上，在行业内对标，现金流扎实、盈利真实、增长可持续、杠杆可控、运营高效，且无指标矛盾」**，以上指标体系可直接嵌入任何量化选股策略，只需根据行业和选股风格调整**阈值+权重**，即可实现批量、精准筛选。
