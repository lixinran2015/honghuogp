### 3. Python代码直接调用

在Python代码中直接使用筛选器：

```python
from backend.strategy.darwin_long_term import DarwinLongTermFilter
from backend.models.stock_data import StockData
from backend.services.market_data_service import MarketDataService
from backend.services.darwin.darwin_data_service import DarwinDataService

# 1. 获取股票数据
market_service = MarketDataService()
stocks_df = market_service.get_realtime_stocks(force_refresh=False, use_warehouse=True)

# 2. 转换为StockData模型
stock_data_list = [StockData.from_dict(row.to_dict()) for _, row in stocks_df.head(10).iterrows()]

# 3. 获取财务数据
darwin_data_service = DarwinDataService()
stock_codes = [stock.code.replace('.SH', '').replace('.SZ', '') for stock in stock_data_list]
financial_data = darwin_data_service.get_financial_data_batch(stock_codes)
industry_info = darwin_data_service.get_industry_info_batch(stock_codes)

# 4. 添加行业信息
for stock in stock_data_list:
    code_6digit = stock.code.replace('.SH', '').replace('.SZ', '')
    if code_6digit in industry_info:
        stock.sector = industry_info[code_6digit]

# 5. 执行筛选
darwin_filter = DarwinLongTermFilter()
result = darwin_filter.filter_darwin_companies(
    stock_data=stock_data_list,
    financial_data=financial_data,
    limit=20
)

# 6. 查看结果
print(f"核心池: {len(result.darwin_core)} 只")
print(f"观察池: {len(result.darwin_watch)} 只")
for stock in result.darwin_core:
    print(f"  {stock.get('name')} ({stock.get('code')})")
```

## 测试检查清单

### 功能测试

- [ ] **数据清洗和次新股过滤**
  - 验证NaN、无限大、0值被正确处理
  - 验证上市不足1年的股票被过滤

- [ ] **排雷指标（9项）**
  - ST/退市风险检查
  - 资不抵债风险检查
  - 持续亏损风险检查
  - 现金流断裂风险检查（区分行业周期）
  - 利息偿付风险检查
  - 商誉减值风险检查
  - 关联交易风险检查
  - 大股东质押风险检查
  - 审计意见风险检查

- [ ] **核心指标检查（7项）**
  - 经营活动现金流（连续3期>0）
  - 净现比（动态阈值，连续3期）
  - 收现比（动态阈值，连续3期）
  - 扣非利润占比（连续3期≥0.8且不下降）
  - 扣非ROE（≥行业中位数，连续3期）
  - 销售毛利率（≥行业中位数，连续3期不下降）
  - 营收同比增长率（≥0且≥行业中位数）

- [ ] **交叉验证规则（5项）**
  - 营收虚增检查
  - 利润造假检查
  - 盲目举债检查
  - 盈利壁垒丧失检查
  - 被动库存积压检查

- [ ] **盈利质量检查**
  - 3-5年净利润趋势（波动率<30%）
  - 毛利率稳定性（单期下降≤5%）

- [ ] **行业地位判断**
  - 排除下滑期行业
  - 市值/营收排名前30%

- [ ] **估值合理性判断**
  - PE在10%-70%分位数 → darwin_core
  - PE>80%分位数 → darwin_watch

## 常见问题排查

### 1. 无法获取财务数据

**问题：** 测试时提示"未获取到财务数据"

**排查步骤：**
1. 检查Tushare服务是否可用：`python -c "from backend.services.tushare_service import TushareService; print(TushareService().available)"`
2. 检查数据库连接：确认PostgreSQL数据仓库可访问
3. 检查股票代码格式：确保是6位数字（如 `600519`）

### 2. 行业周期判断失败

**问题：** 行业周期返回 `unknown`

**排查步骤：**
1. 检查 `config/industry_cash_ratio_thresholds.yaml` 文件是否存在
2. 检查行业名称映射：Tushare的行业名称可能与配置文件中的名称不一致
3. 查看日志中的行业名称映射信息

### 3. 多期财务数据获取失败

**问题：** 无法获取连续3期财务数据

**排查步骤：**
1. 检查Tushare API调用是否成功
2. 检查股票是否为新上市（上市不足1年）
3. 查看日志中的详细错误信息

### 4. 筛选结果为空

**问题：** 所有股票都被过滤掉

**排查步骤：**
1. 查看 `filter_steps` 统计，确定在哪一步被过滤
2. 检查筛选条件是否过于严格
3. 验证测试股票的财务数据是否完整
