# 创业板+科创板筛选策略

## 🎯 为什么选择创业板和科创板？

### 1️⃣ **涨跌幅空间大（±20%）**

| 板块 | 涨跌幅限制 | 特点 |
|------|-----------|------|
| 主板（sh.60, sz.00） | ±10% | 波动小，机会有限 |
| ST 股票 | ±5% | 风险大，不建议 |
| **创业板（sz.30）** | **±20%** | ✅ 波动大，机会多 |
| **科创板（sh.688）** | **±20%** | ✅ 波动大，机会多 |

### 2️⃣ **分时不破均线更有意义**

**主板股票**：
- 涨跌幅小，分时走势相对平稳
- 不破均线的股票很多，但涨幅有限

**创业板/科创板**：
- 波动大，能做到分时不破均线说明**买盘持续强劲**
- 后续上涨空间更大（涨停空间 20%）

### 3️⃣ **成长性更好**

| 特征 | 主板 | 创业板/科创板 |
|-----|------|-------------|
| 上市门槛 | 严格 | 相对宽松 |
| 企业性质 | 传统行业为主 | 高科技、创新企业 |
| 成长性 | 稳定但缓慢 | **高成长潜力** |
| 流动性 | 一般 | 活跃 |

### 4️⃣ **市场活跃度高**

- 资金更关注创业板和科创板
- 题材股、概念股集中
- 更容易出现强势股

## 📊 筛选逻辑

### 股票池
```
创业板：sz.30 开头（约 1500 只）
科创板：sh.688 开头（约 500 只）
合计：约 2000 只股票
```

### 筛选条件

1. **排除涨跌停股票**
   - 涨幅 ≥ 19.5% → 过滤（接近涨停 20%）
   - 跌幅 ≤ -19.5% → 过滤（接近跌停 -20%）
   - 保留涨跌幅在 [-19.5%, +19.5%] 的股票

2. **分时未破均线**
   - 所有 5 分钟 K 线的最低价 ≥ 分时均线
   - 当前价（收盘价）≥ 分时均线
   - 容忍度：0.001 元

### 预期结果

| 阶段 | 数量 | 说明 |
|-----|------|------|
| 初始池 | ~2000 只 | 创业板+科创板全部股票 |
| 排除涨跌停 | ~1800 只 | 过滤掉约 10% |
| 分时未破均线 | **5-30 只** | 最终符合条件的强势股 |

## 🚀 实战意义

### 1. **强势股筛选**
分时不破均线 + 20% 涨跌幅空间 = **超强势股票**

### 2. **买盘持续性**
能在整个交易日保持分时不破均线，说明：
- 买盘持续涌入
- 抛压很小
- 主力控盘能力强

### 3. **后续空间大**
- 主板股票：最多再涨 10%（到涨停）
- **创业板/科创板：最多再涨 20%（到涨停）** ✅

### 4. **题材性强**
创业板和科创板的股票通常有：
- 明确的题材概念
- 资金关注度高
- 容易形成持续性行情

## 📈 使用建议

### 适合场景
✅ 短线交易（T+1 或短期波段）  
✅ 追求高收益高波动  
✅ 有一定风险承受能力  
✅ 熟悉题材和热点  

### 不适合场景
❌ 稳健投资（建议看主板蓝筹）  
❌ 风险厌恶型（波动太大）  
❌ 长期持有（创业板估值波动大）  

## ⚠️ 风险提示

1. **高波动性**
   - 涨 20% 很快，跌 20% 也很快
   - 需要严格止损

2. **流动性风险**
   - 部分小市值股票换手率低
   - 可能出现卖不出的情况

3. **估值风险**
   - 创业板/科创板整体估值偏高
   - 容易出现泡沫破裂

4. **题材炒作**
   - 很多股票是题材驱动，非基本面驱动
   - 题材退潮时跌幅巨大
