# 数据源策略说明

## 双数据源策略

根据数据源特性，采用**easyquotation + akshare** 双数据源策略：

### 1. 实时行情数据（优先 easyquotation）

**数据源优先级**：
1. **easyquotation**（优先）
   - ✅ 更稳定（⭐⭐⭐⭐）
   - ✅ 包含换手率字段
   - ✅ 数据更新速度快（准实时）
   - ✅ 多数据源（QQ/Sina/腾讯）
   - ✅ 抗封锁能力强
   - ⚠️ 只提供行情数据，不提供财务数据

2. **akshare**（备选）
   - ✅ 提供收盘数据
   - ⚠️ 不包含换手率字段
   - ⚠️ 依赖源站爬虫，可能被限流

**获取逻辑**：
```python
# 交易时间：
1. 优先使用 easyquotation 获取实时行情（包含换手率）
2. 如果 easyquotation 失败，fallback 到 akshare

# 休市时间：
1. 使用 akshare 获取今日收盘数据
```

### 2. 财务数据（使用 akshare）

**数据源**：akshare
- ✅ 提供完整的财务数据（ROE、毛利率、净利率等）
- ⚠️ 接口可能不稳定或被限流
- ⚠️ 财务数据实时性要求不高，可以异步获取

**获取策略**：
- **异步获取**：在闭市后后台线程中更新，不阻塞主流程
- **每天一次**：财务数据变化不频繁，每天更新一次即可
- **限制数量**：每次更新前200只股票，避免请求过多

### 3. 数据更新频率

| 数据类型 | 更新频率 | 数据源 | 说明 |
|---------|---------|--------|------|
| 实时行情 | 交易时间每10分钟 | easyquotation（优先）→ akshare（备选） | 包含换手率 |
| 收盘数据 | 闭市后一次 | akshare | 当日收盘数据 |
| 财务数据 | 闭市后一次（异步） | akshare | 每天更新一次，不阻塞主流程 |

## 数据字段说明

### easyquotation 返回的字段
- ✅ **换手率**：`turnover` → 映射为 `换手率`
- ✅ **成交额**：`成交额(万)` → 转换为元
- ✅ **其他行情字段**：最新价、涨跌幅、成交量等

### akshare 返回的字段
- ⚠️ **换手率**：不提供（设置为0）
- ✅ **成交额**：单位是元
- ✅ **其他行情字段**：最新价、涨跌幅、成交量等

## 数据仓库存储

### 股票数据（`data_warehouse/stocks/YYYY-MM-DD.csv`）
- 来源：优先 easyquotation，失败则 akshare
- 字段：代码、名称、最新价、涨跌幅、换手率、成交额等
- **换手率**：如果使用 easyquotation，会有换手率；如果使用 akshare，换手率为0

### 财务数据（`data_warehouse/financial/YYYY-MM-DD.json`）
- 来源：akshare（异步获取）
- 字段：ROE、毛利率、净利率、负债率、经营现金流等
- **更新时机**：闭市后异步更新，不阻塞主流程

## 优势

1. **换手率问题解决**：优先使用 easyquotation，可以获取换手率数据
2. **稳定性提升**：easyquotation 更稳定，akshare 作为备选
3. **性能优化**：财务数据异步获取，不阻塞实时行情更新
4. **容错机制**：如果 easyquotation 失败，自动 fallback 到 akshare

## 注意事项

1. **换手率**：
   - 如果使用 easyquotation，换手率会有数据
   - 如果使用 akshare（备选），换手率为0（N/A）

2. **财务数据**：
   - 闭市后异步更新，可能需要等待
   - 如果 akshare 接口失败，财务数据为0（这是正常的）

3. **数据验证**：
   - 使用"数据仓库"页面可以查看实际存储的数据
   - 检查换手率是否有数据，可以判断使用的是哪个数据源
