# 行业周期数据采集说明

## 一、各数据源是否自动采集

| 数据项 | 来源 | 是否自动采集 | 说明 |
|--------|------|-------------|------|
| **industry_revenue_yoy** | dim_stock.industry + fact_fundamental | ⚠️ 半自动 | 依赖 `fundamental_update`、`sync_stock` 定时任务；industry_cycle_collect 会读取 |
| **industry_index** | Tushare sw_daily | ✅ 自动 | 由 industry_cycle_collect 每日 15:00 后采集 |
| **money_flow** | Tushare + JSON 文件 | ✅ 自动 | 闭市后 DataScheduler 拉取；若权限不足可能为空 |
| **industry_net_cash_dist** | fact_fundamental | ⚠️ 半自动 | 依赖 `fundamental_update`；industry_cycle_collect 会读取 |

## 二、行业周期 collect 是否自动运行

**是**。DataScheduler 在**每日 15:00 后**（闭市时间）会自动执行一次 `update_industry_cycle_data()`，生成 `data_warehouse/industry_cycle/cycle_data_YYYYMMDD.json`。

- 前置条件：后端 DataScheduler 正常运行（随主服务启动）
- 手动触发：可在「定时任务」中配置 `industry_cycle_collect` 任务，或在「数据管理」页手动触发
- 命令行：`python scripts/tools/industry_cycle_update.py --mode collect`

## 三、行业体系统一（申万一级）

**dim_stock.industry** 已统一为 **申万一级行业**（医药生物、食品饮料、电力设备等），由 `sync_industry_from_sw` 脚本从 Tushare `index_member_all` 定期同步。

- **industry_revenue_yoy**、**industry_net_cash_dist**：使用 dim_stock.industry，现为申万一级
- **industry_index**：Tushare sw_daily，申万一级指数
- **money_flow**：仍使用同花顺行业名，需在 `industry_mapping` 中映射到配置名

`industry_mapping` 负责将 **申万/同花顺 行业名 → 配置名**（如 医药生物→生物医药、食品饮料→消费）。若出现「该行业在数据源中无匹配」，需补充相应映射。

## 四、配置建议

### 1. 定时任务（数据管理 / 定时任务 页）

| 任务 | 说明 | 建议频率 |
|------|------|----------|
| **sync_stock** | 同步 dim_stock（新增股票） | 每周一次 |
| **sync_industry** | 将 dim_stock.industry 同步为申万一级 | 可选；industry_cycle_collect 执行时会自动先跑 |
| **fundamental_update** | 更新 fact_fundamental（营收增速、净现比） | 每月或每季 |
| **industry_cycle_collect** | 行业周期数据采集（含申万行业同步） | 每日 15:30（与 DataScheduler 互补） |

- 若 DataScheduler 正常运行，industry_cycle_collect 每日 15:00 后会自动执行，无需单独配置
- 需手动触发时：数据管理页选择对应任务类型 → 立即执行

### 2. 资金流向

- DataScheduler 自动拉取，需 Tushare 资金流向权限
- 若返回空，规则引擎会退化为仅用营收 + 指数判断

## 五、现状小结

| 环节 | 状态 |
|------|------|
| dim_stock / fact_fundamental | 依赖定时任务，需自行配置 |
| money_flow | DataScheduler 自动更新，但可能为空 |
| industry_index（申万行业指数） | ✅ 每日闭市后自动采集 |
| industry_cycle collect | ✅ 每日 15:00 后自动执行 |

## 六、常见问题

### 营收 YoY 全部为 0%

若 `industry_revenue_yoy` 中所有行业均为 0.0%，说明 `fact_fundamental.revenue_growth` 可能未正确填充。


**根因**：Tushare `fina_indicator` 不含 `revenue`、`yoy_sales`，需从 `income` 表取 revenue，从 `or_yoy`/`tr_yoy` 取营收同比。

**已修复**：
- `TushareService.get_financial_data`：增加 `revenue`、`yoy_sales` 请求
- `FinancialDataFetcher`（akshare 路径）：从 `stock_profit_sheet_by_report_em` 提取营业收入、营收同比
- `clean_layer`：当主源缺字段时，从其他 raw 源补充（revenue、yoy_sales、net_profit、ocf_to_revenue）

**修复后**：需重新运行 `fundamental_update` 或 `enhance_financial_data` 更新数据，再执行 `scripts/check/check_revenue_growth_pipeline.py` 验证。

规则引擎在营收为 0 时会标记「疑似数据缺失」，并优先用指数信号判断周期。
