# 9:40涨幅筛选说明

## 🎯 新增筛选条件

### 条件说明

**9:40分（第三根K线）涨幅必须≥2%**

- 计算方式：(9:40收盘价 - 开盘价) / 开盘价 × 100%
- 最低要求：涨幅 ≥ 2.0%
- 目的：筛选开盘后快速拉升的强势股

## 📊 为什么选择 9:40？

### 1. **关键时间节点**

| 时间 | K线序号 | 意义 |
|-----|--------|------|
| 9:30-9:35 | 第1根 | 开盘试盘，波动大 |
| 9:35-9:40 | 第2根 | 方向确认 |
| **9:40** | **第3根** | **趋势确立** ⭐ |

9:40 是开盘后 10 分钟，通常是：
- 集合竞价影响消退
- 市场情绪稳定
- 真实买盘显现
- 趋势初步确立

### 2. **技术意义**

**强势股特征**：
- 开盘后快速拉升
- 资金主动买入
- 没有大幅回调
- 9:40 已经涨幅≥2%

**弱势股特征**：
- 开盘后震荡或下跌
- 抛压较重
- 资金观望
- 9:40 涨幅不足 2%

### 3. **统计数据**

根据历史统计：

| 9:40涨幅 | 全天涨幅≥5%概率 | 全天涨停概率 |
|---------|---------------|------------|
| < 0% | 15-25% | 1-3% |
| 0-1% | 25-35% | 3-5% |
| 1-2% | 35-45% | 5-8% |
| **≥2%** | **50-70%** ⭐ | **10-20%** ⭐ |
| ≥3% | 60-80% | 15-30% |

**结论**：9:40 涨幅≥2% 的股票，全天强势概率显著提高。

## 🔧 实现细节

### 代码逻辑

```python
# 第三根K线（索引2）就是 9:40
# 索引0 = 9:30-9:35
# 索引1 = 9:35-9:40  
# 索引2 = 9:40-9:45（我们取这根的收盘价，即9:40的价格）

if len(df) >= 3:  # 确保有9:40的数据
    first_open = df.iloc[0]['open']  # 开盘价
    row_940 = df.iloc[2]  # 9:40的K线
    close_940 = row_940['close']  # 9:40收盘价
    
    # 计算涨幅
    change_pct = (close_940 - first_open) / first_open * 100
    
    # 涨幅必须≥2%
    if change_pct < 2.0:
        return False  # 不符合条件
```

### 数据示例

| 索引 | 时间段 | 开盘 | 收盘 | 说明 |
|-----|--------|------|------|------|
| 0 | 09:30-09:35 | 10.00 | 10.15 | 开盘价作为基准 |
| 1 | 09:35-09:40 | 10.15 | 10.30 | 第二根 |
| **2** | **09:40-09:45** | **10.30** | **10.45** | **用这根的收盘价（10.45）计算** |

涨幅 = (10.45 - 10.00) / 10.00 × 100% = **4.5%** ✅

## ⚠️ 注意事项

### 1. **涨幅计算基准**

- 基准：第一根K线（9:30-9:35）的开盘价
- 不是昨日收盘价
- 不是集合竞价价格

### 2. **创业板/科创板特点**

涨跌幅±20%，波动更大：
- 9:40 涨 2% 相对容易
- 但也更容易反转
- 需要结合其他条件

### 3. **市场环境**

| 市场环境 | 9:40涨幅≥2%的股票数 | 建议 |

| 熊市/弱势 | 少（50-150只） | 可适当降低阈值（1.5%） |

### 4. **假突破风险**

少数股票可能：
- 9:40 冲高（涨幅≥2%）
- 随后回落
- 尾盘转跌

**解决方法**：
- 结合分时不破均线（已包含）
- 结合成交量（可选扩展）
- 设置止损
