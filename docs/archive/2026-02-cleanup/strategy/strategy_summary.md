# 选股策略总结（2.0版本）

## 一、达尔文公司推荐（长期策略）

### 核心目标
筛选财务稳健、中期趋势向上、行业热度适中的优质公司，适合中长期持有。

### 筛选流程

#### 1. 基础筛选
- **股票池**：S1股票池（优质股票池）
- **财务筛选**：使用 `DarwinLongTermFilter` 筛选财务优质候选
- **数据要求**：需要K线数据（至少60天），但允许没有K线数据的股票通过（使用默认趋势分数）

#### 2. 趋势验证
- **中期趋势判断**（`is_mid_trend_up`）：
  - 价格在 MA60 上方（至少1.01倍）
  - MA20 在 MA60 上方（多头排列）
  
- **趋势分数计算**（`mid_trend_score`，0~1分）：
  - 价位相对MA60：0.9~1.2倍映射到0~1（权重50%）
  - MA20与MA60乖离：0.95~1.15倍映射到0~1（权重50%）

#### 3. 板块热度加权
- **板块热度因子**（`sector_heat_factor`）：
  - 使用 `swing_heat_score`（波段热度分数）
  - 0~20分映射到0~1（没有板块信息时返回0.5）

#### 4. 最终评分公式
```
最终得分 = 财务评分 × 0.6 + 趋势分数 × 0.25 + 板块热度因子 × 0.15
```

#### 5. 特殊处理
- **无K线数据**：允许通过，使用默认趋势分数0.5
- **K线数据不足60天**：允许通过，使用默认趋势分数0.5
- **行业龙头**：单独标记（45只预定义龙头股票）

### 返回字段
- `finalScore`: 最终得分（0~100）
- `trendScore`: 趋势分数（0~1）
- `sectorHeat`: 板块热度因子（0~1）
- `longTermTag`: 长期标签（基于最终得分）
- `reason`: 推荐理由
- `advice`: 投资建议

## 二、波段股票推荐（中期策略）

### 核心目标
筛选上升趋势中合理回踩的股票，来自热度较高的板块，适合波段持有。

### 筛选流程

#### 1. 基础筛选
- **原始候选**：从 `SwingPullbackFilter` 获取候选股票
- **数据要求**：必须有K线数据（至少40天）

#### 2. 板块环境筛选
- **板块热度要求**：
  - `swing_heat_score >= 8`（如果没有板块数据则允许通过）
  - 使用 `FactSectorHeatSnapshot` 表获取板块热度

#### 3. 趋势验证
- **趋势分数要求**：
  - `mid_trend_score >= 0.3`（从0.5降低到0.3，允许更多股票通过）
  
- **回踩结构验证**（`is_valid_pullback`）：
  - ✅ 30日收益 >= 5%（整体上升趋势）
  - ✅ 10日收益 < 5%（有回踩迹象，不能持续大涨）
  - ✅ 10日收益 > -15%（不能深跌）
  - ✅ 5日收益 < 5%（不能持续大涨）
  - ✅ 10日和5日不能同时 > 3%（不能都在上涨）

#### 4. 流动性筛选
- **成交额要求**：
  - 日均成交额 >= 5000万（如果没有数据则允许通过）

#### 5. 最终评分公式
```
最终得分 = 基础波段得分 × 0.5 + 趋势分数 × 0.3 + 板块热度因子 × 0.2
```

### 过滤统计
- 无K线数据
- 板块热度不足（swing_heat_score < 8）
- 趋势分数不足（< 0.3）
- 非有效回踩结构
- 成交额不足（< 5000万）

### 返回字段
- `reason`: "波段策略2.0：上升趋势中回踩，板块热度X.X，趋势分数X.XX"
- `advice`: "适合波段持有，关注趋势延续"
- `volumePricePattern`: "趋势回踩"

## 三、短线股票推荐（短期策略）

### 核心目标
筛选热门板块中的龙头或强势股票，具有明显的短线动能，适合短线操作。

### 筛选流程

#### 1. 基础筛选
- **原始候选**：从短线筛选策略获取候选股票
- **数据要求**：必须有K线数据（至少5天）

#### 2. 板块环境筛选
- **板块热度要求**：
  - `short_heat_score >= 10`（如果没有板块数据则允许通过）
  - 使用 `FactSectorHeatSnapshot` 表获取板块短线热度

#### 3. 短线动能验证
- **动能判断**（`is_short_momentum_ok`）：
  - 最近5日最高涨幅 > 8%
  - 至少出现过一根实体阳线 > 5%
  
- **动能分数计算**（`short_momentum_score`，0~1分）：
  - 最大涨幅：0~12%映射到0~1（权重60%）
  - 平均涨幅：0~5%映射到0~1（权重40%）

#### 4. 龙头加分
- **龙头角色识别**：
  - 使用 `FactSectorLeaderSnapshot` 表获取龙头信息
  - `leader`: 加分1.0
  - `sub_leader`: 加分0.7
  - 其他: 加分0.3

#### 5. 最终评分公式
```
最终得分 = 基础短线得分 × 0.4 + 动能分数 × 0.3 + 板块热度因子 × 0.2 + 龙头加分 × 0.1
```

### 过滤统计
- 无K线数据
- 无板块数据（允许通过但降低分数）
- 板块热度不足（short_heat_score < 10）
- 短线动能不足（不满足动能要求）

### 返回字段
- `reason`: "短线策略2.0：热门板块强势股，板块热度X.X，动量分数X.XX，龙头角色=XXX"
- `advice`: "买入"
- `volumePricePattern`: "量增价升"

## 四、交易验证层（统一工具函数）

### 1. 趋势验证函数

#### `is_mid_trend_up(kline)`
- **功能**：判断中期趋势是否健康
- **规则**：
  - 价格在 MA60 上方（至少1.01倍）
  - MA20 在 MA60 上方
- **返回**：bool

#### `mid_trend_score(kline)`
- **功能**：计算中期趋势分数（0~1）
- **计算方式**：
  - 价位相对MA60：0.9~1.2倍映射到0~1（权重50%）
  - MA20与MA60乖离：0.95~1.15倍映射到0~1（权重50%）
- **返回**：float (0~1)

### 2. 波段回踩验证函数

#### `is_valid_pullback(kline)`
- **功能**：判断是否为有效的波段回踩
- **规则**：
  - 30日收益 >= 5%（整体上升趋势）
  - 10日收益 < 5%（有回踩迹象）
  - 10日收益 > -15%（不能深跌）
  - 5日收益 < 5%（不能持续大涨）
  - 10日和5日不能同时 > 3%（不能都在上涨）
- **返回**：bool

### 3. 短线动能验证函数

#### `is_short_momentum_ok(kline)`
- **功能**：判断是否具有短线动能
- **规则**：
  - 最近5日最高涨幅 > 8%
  - 至少出现过一根实体阳线 > 5%
- **返回**：bool

#### `short_momentum_score(kline)`
- **功能**：计算短线动能分数（0~1）
- **计算方式**：
  - 最大涨幅：0~12%映射到0~1（权重60%）
  - 平均涨幅：0~5%映射到0~1（权重40%）
- **返回**：float (0~1)

### 4. 板块热度加权函数

#### `sector_heat_factor(sector_snapshot, strategy_type)`
- **功能**：将板块热度转换为0~1权重
- **参数**：
  - `strategy_type`: "swing"使用`swing_heat_score`，"short"使用`short_heat_score`，其他使用`heat_score`
- **计算方式**：0~20分映射到0~1（没有板块信息时返回0.5）
- **返回**：float (0~1)

## 五、数据依赖

### 必需数据表
1. **FactSectorHeatSnapshot**：板块热度快照
   - `swing_heat_score`: 波段热度分数（0~20）
   - `short_heat_score`: 短线热度分数（0~20）
   - `heat_score`: 综合热度分数（0~20）

2. **FactSectorLeaderSnapshot**：板块龙头快照（可选）
   - `role`: 龙头角色（leader/sub_leader/其他）
   - `stock_code`: 股票代码

3. **K线数据**：
   - 达尔文：至少60天（允许缺失，使用默认分数）
   - 波段：至少40天（必需）
   - 短线：至少5天（必需）

### 数据更新
- 板块热度数据通过 `update_sector_heat_snapshot.py` 脚本更新
- 窗口ID：`current_rolling_30d`（滚动30天窗口）

## 六、去重机制

### 去重规则
- **统一使用6位股票代码**（去除`.SH`、`.SZ`后缀）
- **在转换为StockData时去重**（保留第一个）
- **在精炼后返回时去重**（保留得分最高的）
- **在降级方案中也去重**

### 去重位置
1. 原始推荐数据转换为StockData时
2. 精炼后返回结果时
3. 降级方案（错误处理）时

---

## 七、策略特点总结

### 达尔文（长期）
- ✅ 财务质量优先（60%权重）
- ✅ 允许无K线数据（使用默认分数）
- ✅ 趋势验证作为辅助（25%权重）
- ✅ 板块热度作为环境因子（15%权重）

### 波段（中期）
- ✅ 严格回踩验证（30日上涨+10日回踩）
- ✅ 板块热度要求（swing_heat_score >= 8）
- ✅ 趋势分数要求（>= 0.3）
- ✅ 流动性要求（成交额 >= 5000万）

### 短线（短期）
- ✅ 板块热度要求（short_heat_score >= 10）
- ✅ 短线动能验证（5日最高涨幅 > 8%）
- ✅ 龙头加分机制（leader/sub_leader）
- ✅ 允许无板块数据（但降低分数）
