## 一、项目整体架构

```

├── backend/              # FastAPI 后端
│   ├── app.py           # 主入口，挂载路由 + 启动调度
│   ├── api/             # REST API 路由
│   ├── services/        # 业务服务层

```

**技术栈**：FastAPI + Vue3 + PostgreSQL + SQLAlchemy + Tushare/AkShare/Baostock

## 二、启动流程

### 2.1 后端启动 (app.py)

1. 加载配置与日志
2. 创建 FastAPI 应用，注册 CORS、中间件
3. 挂载所有 API 路由（持仓、推荐、启动、板块、监控、数据管理等）
4. 初始化 `DataWarehouse` 和 `DataScheduler`
5. 调用 `scheduler.start_scheduler()`，启动后台线程

### 2.2 调度服务启动 (DataScheduler)

- **数据完整性**：启动时检查最近 5 个交易日数据，有缺失则后台补全
- **任务检查线程**：每分钟执行一次 `_check_and_run_scheduled_tasks()`
- **主调度循环**：
  - 推荐计算：09:15 / 11:30 / 13:00 / 15:00
  - 9:40 监控：工作日 9:35 自动启动
  - 财务数据：每月 1 号 20:00 更新
  - 板块日线、资金流向等：闭市后更新

## 三、定时任务体系

### 3.1 任务配置表 (dim_scheduled_task)

| 任务名称 | 显示名 | 执行时间 | 任务类型 | 说明 |
|---------|--------|----------|----------|------|
| daily_update | 日线数据更新 | 15:30 工作日 | daily_update | 从快照表更新日线 |
| fundamental_update | 财务数据更新 | 16:00 周一 | fundamental_update | Tushare 财务 |
| refresh_snapshot | 股票快照刷新 | 09:15 工作日 | refresh_snapshot | 刷新快照并生成推荐 |
| sector_heat_update | 板块热度更新 | 15:00 工作日 | sector_heat_update | 板块热度 |
| sector_leaders_update | 板块龙头更新 | 15:30 工作日 | sector_leaders_update | 板块龙头 |
| sync_stock | 更新股票列表 | 09:00 周一 | sync_stock | 股票基础信息 |
| sync_trade_calendar | 同步交易日历 | 08:00 周一 | sync_trade_calendar | 交易日历 |
| guba_popularity_crawl_morning | 股吧人气榜（早上） | 09:00 工作日 | guba_popularity_crawl | 东方财富股吧爬虫 |
| guba_popularity_crawl_noon | 股吧人气榜（中午） | 12:00 工作日 | guba_popularity_crawl | 同上 |
| s1_universe_update | S1股票池更新 | 09:10 工作日 | s1_universe_update | S1 筛选池 |

### 3.2 任务执行流程

```
DataScheduler._check_and_run_scheduled_tasks()
    ↓ 每分钟
查询 DimScheduledTask (is_enabled=True)
    ↓ 匹配 schedule_time、schedule_days、last_run_at
提取 task_name, task_type
    ↓ 后台线程
run_task() 根据 task_type 分发：
    ├─ guba_popularity_crawl → GubaPopularityCrawler
    ├─ sync_trade_calendar   → sync_trade_calendar()
    └─ 其他                  → DataManagementService.trigger_data_update()
```

## 四、数据流（ETL）

### 4.1 数据分层

```
外部数据源                    Raw 层                     Clean 层
─────────────────────────────────────────────────────────────────
Tushare Pro    ──────►  raw_daily_price_qfq    ──────►  fact_daily_price_qfq
AkShare        ──────►  raw_*                   ──────►  业务表
Baostock       ──────►  raw_*                   ──────►
东方财富股吧    ──────►  fact_guba_popularity
```

### 4.2 日线更新流程 (daily_update)

```
DataManagementService._run_daily_update()
    ↓
update_daily_prices_from_snapshot()
    ↓
1. get_latest_trade_date() 获取最近交易日
2. MarketDataService 或 Baostock/AkShare 拉取日线
3. RawDataLayer.upsert_daily_price() 写入 raw 层
4. CleanDataLayer 清洗、去重、写入 fact_daily_price_qfq
```

### 4.3 快照与推荐 (refresh_snapshot)

```
DataManagementService._run_refresh_snapshot()
    ↓
refresh_snapshot_and_recommendations()
    ↓
1. 刷新 StockSnapshotService 快照（基于实时行情）
2. 可选触发推荐计算
```

## 五、推荐计算流程

### 5.1 触发方式

- **定时**：09:15 / 11:30 / 13:00 / 15:00（DataScheduler 主循环）
- **手动**：通过 refresh_snapshot 或 API 触发

### 5.2 计算链路 (RecommendationScheduler)

```
run_recommendation_calculation(snapshot_time)
    ↓
1. StockSnapshotService.create_snapshot() 创建数据快照
2. StockSnapshotService.get_latest_snapshot() 获取快照
3. MarketDataService.get_historical_kline() 获取 120 日 K 线
4. StrategyCalculationService.calculate_all_strategies() 计算策略
5. RecommendationEngine.run() 生成推荐
6. RecommendationResultService 写入推荐池
```

## 六、核心业务模块

### 6.1 股票启动（三阶段）

```
金叉候选 ──► 待候选监控(2/3条件) ──► 已启动
    │              │                    │
    │              │                    └─ 退出检查（破20日线）
    │              └─ 监控服务检测条件满足
    └─ 5日金叉10日 + 核心条件 + 辅助条件 + 风险排除
```

- **金叉候选**：批量扫描 S1 股票池，筛选金叉并计算得分
- **待监控**：满足 2/3 核心条件，进入 watch 表，定时检查
- **已启动**：条件全满足 → started；退出检查（破 20 日线 → is_exited）

**相关服务**：`StockStartupFilter`, `StartupExitChecker`, `StartupWatchService`

### 6.2 持仓/操作池 (holdings)

- 持仓 CRUD、盈亏、追高风险、AI 操作建议
- 依赖：新浪实时行情、K 线服务

### 6.3 跟踪列表 (watchlist)

- 自选股、分时、人气榜
- 可与已卖出“站稳10日线+多头”自动加入逻辑联动

### 6.4 板块/题材

- 板块热度、龙头、轮动
- 数据源：Tushare、东方财富

### 6.5 股吧人气榜

- 爬虫：`GubaPopularityCrawler`（需 ChromeDriver）
- 定时：早上 9:00、中午 12:00

## 七、数据库连接

### 7.1 共享引擎 (data_warehouse/db.py)

- `get_shared_engine()`：全局单例，pool_size=5, max_overflow=5
- `get_session()`：基于共享引擎的 Session
- 目的：避免各服务独立 `create_engine` 导致连接数超限

### 7.2 使用共享引擎的服务

- WarehouseService、TushareService、RawDataLayer、CleanDataLayer
- RecommendationResultService、StockSnapshotService、IntradayService
- SectorService、DarwinDataService、LimitupEmotionService 等
