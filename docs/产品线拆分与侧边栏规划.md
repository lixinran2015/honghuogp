## 产品线拆分与侧边栏规划（2026-03）

本项目功能逐渐增多，目前的核心目标其实非常聚焦：

> **围绕「短线启动龙头」，每天筛选出少数标的，给出清晰的买入 / 卖出点，并能用同一套逻辑做回测与复盘。**

为避免后续演进再次发散，这里把现有模块按「产品线 / 域」做一次固定化的拆分，并给出一套精简版的侧边栏规划，供后续开发和重构时对齐。

---

### 一、三层结构概览

- **启动龙头产品线（S）**：短线启动、龙头识别、买卖点、回测 —— 当前的「旗舰」主线。
- **周期股产品线（C）**：针对周期行业（资源、上游、库存周期等）的中期仓位管理（目前处于规划 + 初始实现阶段）。
- **共享底座（B）**：数据仓库、行情、因子、账户、AI、通用回测等，S / C 两条产品线公共依赖。

物理上仍保持一个仓库；在代码、路由和菜单层面按照 S / C / B 边界管理，后续如有必要再做部署级拆分。

---

### 二、后端模块 → 产品线映射

#### 1. 数据与基础设施（B，S/C 必须）

- **共享底座（B）**
  - `data_warehouse.service.warehouse_service`
  - `backend/services/data/data_management_service.py`
  - `backend/api/data_management.py`
  - 各类 `data_warehouse/etl/*` / 数据更新脚本

说明：  
这些是所有策略的前置条件（完整的日线 / 前复权 / 交易日历等），属强共享、强依赖模块。

#### 2. 启动 / 龙头相关（S 核心）

- **启动龙头产品线（S）**
  - `backend/services/stock/stock_startup_filter.py`
  - `backend/services/stock/startup_backtest_service.py`
  - `backend/services/recommendation/multi_dimension_scorer.py`
  - `backend/services/recommendation/stock_recommender.py`（推荐池与启动有强耦合）
  - `backend/api/startup/*.py`（启动诊断 / 回测 / 监控 API）
  - `backend/api/leaders.py`（`/api/industry-leaders` 等）
  - `backend/api/sectors/hot_sector*.py`（热门板块 / 板块领涨）

#### 3. 因子 / 投研服务（B，共享，S 当前已使用）

- **共享底座（B），S / C 均可使用**
  - `backend/services/factors/factor_calculator.py`
  - `backend/services/factors/factor_screener.py`
  - `backend/api/factors.py`

说明：  
当前 S 线已使用 `mom_20d` / `turnover_20d` 等技术因子参与启动评分，后续 C 线可叠加估值/盈利因子。

#### 4. 通用回测 / 策略引擎（B）

- **共享底座（B）**
  - `backend/services/backtest/backtest_engine.py`
  - `backend/api/backtest.py`（`/api/backtest/*` + `/api/backtest/strategy-config/run`）
  - `backend/api/strategies/engines.py` / `backend/api/engines.py`（策略说明接口）

说明：  
这些模块为「任意单票策略」提供基础回测能力，目前主要在 AI 策略助手和通用回测页中使用，未来也可以为周期股线复用。

#### 5. AI / 辅助分析（B）

- **共享底座（B），按需挂入 S / C**
  - `backend/services/analysis/ai_analysis_service.py`（单票 AI 分析、龙头诊断、持仓建议等）
  - `backend/api/strategy_ai.py` + `backend/services/strategy/ai_strategy_assistant.py`
  - `backend/api/knowledge/ai_chat.py`

说明：  
这些模块不直接改变买卖逻辑，主要提供解释、策略草案生成、持仓建议等增值能力。

#### 6. 账户 / 交易 / 其它外围（B）

- **共享底座（B）**
  - `backend/api/accounts/holdings.py` / `sold_stock.py`
  - `backend/api/watch/*`（`watchlist`, `monitor_near5`, `startup_watch`）
  - `backend/api/social/guba_popularity.py`
  - `backend/api/market.py` / `backend/api/money_flow.py` 等

说明：  
账户与行情是天然共享资源，S / C 两条线都需要。

#### 7. 周期股相关（C 线候选）

目前周期股线还在「规划 + 零散实现」阶段，已有的主要是一些行业周期相关文档与视图（见后端/前端对应部分）。  
未来可以在 `backend/services/cycle/` 下集中沉淀周期股专用逻辑，再通过 `/api/cycle/*` 暴露。

### 三、前端视图 / 路由 → 产品线映射

#### 1. 启动龙头产品线（S 核心）

- **核心页面（S）**
  - `StockStartupView.vue` → `/startup`：启动监控主页。
  - `StartupBacktestView.vue` → `/startup-backtest`：启动策略整体回测 + 因子分组统计。
  - `StartupPerformanceView.vue` → `/startup-performance`：启动信号后续表现。
  - `StockDiagnoseView.vue` → `/diagnose`：单票启动诊断。
  - `MonitorNear5View.vue` → `/monitor-near5`：分时监控，可聚焦启动票。

- **板块 / 龙头（S / C 共享，但 S 优先用）**
  - `HotSectorView.vue` → `/hot-sector`：热门板块。
  - `HotSectorStockListView.vue` → `/hot-sector-stocks`：板块成份股。
  - `IndustryLeadersView.vue` → `/industry-leaders`：板块/行业龙头。
  - `AbsoluteLeadersView.vue` → `/absolute-leaders`：绝对龙头。
  - `SectorBoardLeadersView.vue` → `/sector-board-leaders`：板块领涨。

#### 2. 因子 / 通用回测 / AI（共享底座 B，建议放「投研中心 / 高级」）

- `BacktestView.vue` → `/backtest`：通用单票策略回测。
- `FactorExperimentView.vue` → `/factor-lab`：因子实验室。
- `AIStrategyAssistantView.vue` → `/ai-strategy`：AI 策略助手（自然语言 → 策略配置 → 回测）。

#### 3. 周期股产品线（C 候选页面）

目前周期股线的 UI 和逻辑还比较分散，以下视图可作为 C 线的基础：

- `ThemeRotationView.vue` → `/theme-rotation`：长期主题轮动，可演化为「周期行业轮动」主页。
- `IndustryCycleView.vue` → `/industry-cycle`：行业周期阶段判断，可升级为「周期股仪表盘」。
- `DarwinView.vue` → `/darwin`：长期策略（核心持仓），与周期股配置有一定天然适配性。

建议后续在 Sidebar 中为周期股线单独开一组（见后文侧边栏规划）。

#### 4. 账户 / 情绪 / 知识库等外围（B）

这些视图与具体产品线弱相关，主要服务于账户查看、复盘与知识沉淀：

- `HoldingsView.vue` → `/holdings`
- `SoldStockView.vue` → `/sold-stock`
- `RecommendationsView.vue` / `RecommendationPoolView.vue`
- `SentimentAnalysisView.vue` → `/sentiment`
- `KnowledgeBaseView.vue` → `/knowledge-base`
- `DailyReviewView.vue` → `/daily-review`
- `GubaPopularityView.vue` → `/guba-popularity`

### 四、精简版 Sidebar 规划（聚焦启动龙头 & 清晰分组）

目标：  
打开系统时，左侧导航一眼就能看出「启动龙头这条线」，其它功能放到更靠后的分组、命名清晰，减少心智负担。

#### 1. 建议的分组结构（高层）

1. **选股中心**（账户 & 智能推荐）
2. **启动龙头**（本项目当前的首要产品线）
3. **板块与龙头**（热点板块 / 龙头 / 资金流）
4. **周期与长期**（周期股相关 + 长期策略）
5. **投研工具**（因子实验室 / 通用回测 / AI 策略助手）
6. **复盘与情绪**
7. **设置与数据**

#### 2. 对应到 `Sidebar.vue` 的配置草案

> 这里只给出逻辑分组和路径，不直接改代码，后续在 `Sidebar.vue` 的 `menuGroups` 中按此调整即可。

- **选股中心**
  - `/holdings` → 我的自选 / 持仓
  - `/recommendation-pool` → 智能推荐池
  - `/stock-selector` → 通用选股器（如暂时不常用，也可下移到投研工具）

- **启动龙头**
  - `/startup` → 启动监控
  - `/startup-backtest` → 启动策略回测
  - `/startup-performance` → 启动表现
  - `/diagnose` → 单票诊断
  - `/monitor-near5` → 分时监控（聚焦启动池）

- **板块与龙头**
  - `/hot-sector` → 热门板块
  - `/hot-sector-stocks` → 板块成份股
  - `/industry-leaders` → 板块龙头
  - `/absolute-leaders` → 绝对龙头
  - `/sector-board-leaders` → 板块领涨
  - （可选）`/money-flow-heavy` → 大额资金净流入

- **周期与长期**（周期股产品线 C）
  - `/industry-cycle` → 行业周期
  - `/theme-rotation` → 长期主题轮动
  - `/darwin` → 达尔文长期策略（核心仓候选）

- **投研工具**
  - `/backtest` → 通用策略回测
  - `/factor-lab` → 因子实验室
  - `/ai-strategy` → AI 策略助手
  - `/knowledge-base` → 知识库（也可放到复盘分组）

- **复盘与情绪**
  - `/daily-review` → 每日复盘
  - `/sentiment` → 情绪分析
  - `/guba-popularity` → 人气榜
  - `/sold-stock` → 已卖出（复盘用）

- **设置与数据**
  - `/strategy` → 策略引擎说明（strategy engines 说明页）
  - `/data-management` → 数据管理 / 日线更新
  - `/stock-financial` → 财务数据
  - `/scheduled-task` → 定时任务
  - `/trade-calendar` → 交易日历

### 五、使用方式与后续演进建议

1. **新功能上线前**，先判断归属：
   - 明确是「启动龙头线（S）」的增强，还是「周期股线（C）」的增强，还是「共享底座（B）」的扩展；
   - 对应在本文件中补一行映射，保持文档和实现同步。

2. **前端导航改动**时，以本文件的侧边栏规划为参考，避免菜单名称和分组再次发散。

3. 将来如果需要为不同用户单独提供「极简启动版」或「周期股版」，可以：
   - 通过环境变量 / 配置控制：加载哪几个菜单分组、注册哪些路由；
   - 仍复用同一套后端，只在路由层做产品化裁剪。
