# 波段选股结果报告

## 需求梳理

### S3（波段节奏选股）
从S2中筛选，条件：
1. **趋势向上**：收盘价 > MA20
2. **回踩确认**：价格在MA10-MA20附近回踩（最好1~3根K线）
3. **缩量回落**：最近成交量相比前期减少（缩量至少20%）
4. **不破MA20**：最近3根K线的最低价都不低于MA20

**目标**：输出40~100只"波段候选股"

### S4（买点判断）
在S3候选里，每天检查以下买点信号（满足任意一个即可）：
1. **放量阳线**：今日成交量 > 5日均量 * 1.2 且 收盘价 > 开盘价
2. **突破3日高点**：收盘价 > 最近3日最高价
3. **MACD金叉**：MACD线上穿信号线
4. **反包阳线**：昨日阴线，今日阳线且收盘价 > 昨日最高价

### 卖点策略

#### 短波段（快节奏）
- 跌破MA10卖
- 弱转强失败3日卖
- 放量长上影卖

#### 中波段（安全）
- 跌破MA20卖
- MA10、MA20死叉卖
