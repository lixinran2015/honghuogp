# 行业龙头股票数据批量导入说明

## 概述

系统支持一次性批量导入各行各业的龙头股票数据，这些数据可以用于：
1. **AI诊断参考**：在龙头诊断时，AI可以参考行业龙头数据
2. **RAG知识库**：作为知识库文档，支持智能问答
3. **数据查询**：快速查询某行业的龙头股票

## 数据库表结构

### `dim_industry_leader` 表

存储静态的、权威的行业龙头股票数据。

**主要字段：**
- `ts_code`: 股票代码
- `stock_name`: 股票名称
- `industry`: 所属行业
- `leader_type`: 龙头类型（行业龙头/板块龙头/细分龙头）
- `leader_reason`: 龙头判断理由
- `main_business`: 主营业务
- `market_cap`: 市值（亿元）

## 使用步骤

### 1. 创建数据库表 ⚠️ **必须先执行此步骤！**

执行SQL迁移脚本创建 `dim_industry_leader` 表：

#### 方法1：使用psql命令行
```bash
psql -U your_user -d your_database -f migrations/create_industry_leaders_table.sql
```

#### 方法2：使用数据库管理工具
使用 pgAdmin、DBeaver 等工具，打开并执行文件：
```
migrations/create_industry_leaders_table.sql
```

#### 方法3：使用Python脚本（推荐，最简单）
```bash
python backend/scripts/tools/create_industry_leaders_table.py
```

这个脚本会自动：
- 检查表是否已存在
- 读取SQL迁移文件
- 创建表和索引
- 提供清晰的日志输出

#### 方法4：手动执行SQL（适用于高级用户）
```python
from data_warehouse.service.warehouse_service import WarehouseService
from sqlalchemy import text

ws = WarehouseService()
session = ws.get_session()
with open('migrations/create_industry_leaders_table.sql', 'r', encoding='utf-8') as f:
    session.execute(text(f.read()))
session.commit()
session.close()
print("✅ 表创建成功！")
```

**注意：** 如果跳过此步骤，导入数据时会报错：`relation "dim_industry_leader" does not exist`

## 数据来源

### 1. **手动整理**（当前主要方式）
- 根据行业研究报告、券商研报整理
- 参考 `backend/scripts/tools/add_industry_leaders_sectors.py` 中已有的45只行业龙头股票
- 优点：准确、权威
- 缺点：需要人工维护

### 2. **自动获取**（推荐）
使用脚本自动从Tushare API获取：

```bash
# ⭐ 推荐：综合评分法（市值+营收+ROE+增长率）
python backend/scripts/tools/auto_fetch_industry_leaders.py --industry 新能源 --method comprehensive --top 3 --import-db

# 按市值获取所有行业的龙头（每个行业取前3只）
python backend/scripts/tools/auto_fetch_industry_leaders.py --method market_cap --top 3 --import-db

# 按营收获取所有行业的龙头
python backend/scripts/tools/auto_fetch_industry_leaders.py --method revenue --top 3 --import-db

# 只处理指定行业
python backend/scripts/tools/auto_fetch_industry_leaders.py --industry 新能源 --method market_cap --top 3

# 导出到JSON文件（不导入数据库）
python backend/scripts/tools/auto_fetch_industry_leaders.py --method market_cap --export leaders.json
```

**识别标准：**

| 方法 | 标准 | 优点 | 缺点 | 推荐度 |
|------|------|------|------|--------|
| **市值法** | 市值最大的N只 | 数据易得、反映市场认可度 | 可能包含被高估的公司、忽略盈利能力 | ⭐⭐⭐ |
| **营收法** | 营收最大的N只 | 反映业务规模 | 可能包含低质量公司、忽略盈利能力 | ⭐⭐⭐ |
| **综合评分法** | 市值30% + 营收25% + ROE25% + 增长率20% | 综合考虑规模、盈利能力、成长性 | 需要更多数据、API调用较多 | ⭐⭐⭐⭐⭐ |

**综合评分法说明：**
- **市值（30%）**：反映市场认可度和规模
- **营收（25%）**：反映业务规模
- **ROE（25%）**：反映盈利能力
- **营收增长率（20%）**：反映成长性

**优点：**
- 自动化，无需手动整理
- 数据实时更新
- 覆盖全面
- 综合评分法更可靠

**缺点：**
- 市值法/营收法可能包含一些非真正龙头的股票
- 需要Tushare API权限
- 综合评分法需要更多API调用（建议单个行业使用）

### 3. **混合方式**（推荐）
1. 先用自动获取脚本获取初步数据
2. 人工审核和筛选，去除不符合的股票
3. 补充龙头判断理由和主营业务信息
4. 导入数据库和RAG知识库

### 4. **专家标注**
- 邀请行业专家标注
- 可以基于自动获取的数据，由专家确认和补充

## 在AI诊断中的应用

导入的行业龙头数据会在以下场景中使用：

1. **龙头诊断时**：AI会参考行业龙头数据，判断目标股票是否是龙头
2. **RAG查询时**：用户询问"XX行业的龙头股票有哪些"时，可以从知识库检索
3. **对比分析**：可以将目标股票与行业龙头进行对比

## 注意事项

1. **数据准确性**：确保导入的数据准确，因为会影响AI判断
2. **定期更新**：行业龙头可能会变化，建议定期更新数据
3. **数据验证**：导入前会验证股票代码是否存在
4. **去重处理**：同一股票在同一行业只会保留一条记录（使用ON CONFLICT更新）
